## 1. 截图原理与场景

### 1.1 截图的两种路径

```
路径 A：解码指定帧 → 输出图片
  ffmpeg -ss 30 -i video.mp4 -frames:v 1 frame.jpg
  特点：精确，但需要解码到该帧

路径 B：只解码关键帧（I帧）→ 输出图片
  ffmpeg -skip_frame noref -i video.mp4 -vf select='eq(pict_type\,I)' frames/key_%04d.jpg
  特点：极快（跳过 P/B 帧），但只在关键帧处截图

路径 C：实时覆盖截图（直播监控）
  ffmpeg -i rtmp://... -vf "fps=1/30" -update 1 -y preview.jpg
  特点：始终只保留一张最新图片（见 Article 19）
```

### 1.2 应用场景矩阵

| 场景 | 方案 | 关键参数 |
|------|------|----------|
| 视频封面（单张） | 取某时刻截图 | `-ss 5 -frames:v 1` |
| 进度条预览（雪碧图） | 等间隔批量截图 → tile 合并 | `fps=1/10 + tile` |
| 内容审核（关键帧） | 关键帧批量提取 | `select='eq(pict_type\,I)'` |
| 直播监控（实时预览） | 覆盖式截图 | `-update 1 -y` |
| 动态预览（GIF） | 抽帧生成 GIF | `fps=10 + palette` |
| SEO 封面（智能选帧） | 选高质量帧 | `select='gt(scene\,0.4)'` |

## 2. 单帧截图

### 2.1 基础截图命令

```bash
# 取第 5 秒的截图（JPEG）
ffmpeg -ss 5 -i video.mp4 -frames:v 1 -q:v 2 thumbnail.jpg

# 取第 5 秒的截图（PNG，无损）
ffmpeg -ss 5 -i video.mp4 -frames:v 1 thumbnail.png

# 指定输出尺寸
ffmpeg -ss 5 -i video.mp4 -frames:v 1 -vf "scale=320:-1" -q:v 2 thumb_320.jpg

# 保持宽高比，限制最大尺寸（320x240 盒子内缩放）
ffmpeg -ss 5 -i video.mp4 -frames:v 1 \
  -vf "scale=320:240:force_original_aspect_ratio=decrease,pad=320:240:(ow-iw)/2:(oh-ih)/2" \
  -q:v 2 thumb_boxed.jpg
```

**-q:v 质量参数**（JPEG，数值越小质量越高）：

| q:v | 质量 | 文件大小 | 适用场景 |
|-----|------|----------|----------|
| 1-2 | 极高 | 大 | 封面/展示图 |
| 3-5 | 高（推荐）| 中等 | 通用缩略图 |
| 10-20 | 中 | 小 | 进度条预览 |
| 21-31 | 低 | 极小 | 大量雪碧图内子图 |

**色彩空间处理（重要）**：

某些视频使用 limited-range YUV（电视标准，`yuv420p(tv, ...)`），而 MJPEG 编码器要求 full-range YUV，会导致截图失败并报错：

```
[mjpeg @ ...] Non full-range YUV is non-standard, set strict_std_compliance to at most unofficial to use it.
Error while opening encoder - maybe incorrect parameters
```

**解决方案**（任选一种）：

```bash
# 方案 1：显式指定 full-range 像素格式（推荐）
ffmpeg -ss 5 -i video.mp4 -frames:v 1 -pix_fmt yuvj420p -q:v 2 thumbnail.jpg

# 方案 2：降低严格性检查
ffmpeg -ss 5 -i video.mp4 -frames:v 1 -strict unofficial -q:v 2 thumbnail.jpg

# 方案 3：用滤镜转换色彩空间
ffmpeg -ss 5 -i video.mp4 -frames:v 1 -vf format=yuvj420p -q:v 2 thumbnail.jpg
```

**推荐方案 1**（`-pix_fmt yuvj420p`，j = JPEG full-range），兼容性最好。如果所有截图命令都遇到此问题，可在基础命令中默认加上此参数。

### 2.2 时间点指定方式

```bash
# HH:MM:SS 格式
ffmpeg -ss 00:01:30 -i video.mp4 -frames:v 1 frame.jpg

# 秒数（小数）
ffmpeg -ss 90.5 -i video.mp4 -frames:v 1 frame.jpg

# 百分比（需先获取时长）
DURATION=$(ffprobe -v error -show_entries format=duration -of csv=p=0 video.mp4)
MIDPOINT=$(echo "$DURATION * 0.1" | bc)  # 10% 处
ffmpeg -ss "$MIDPOINT" -i video.mp4 -frames:v 1 frame.jpg
```

### 2.3 自动取最佳封面帧

```bash
# 取场景变化显著的帧（change=场景变化分数 0-1，>0.4 表示显著变化）
ffmpeg -i video.mp4 \
  -vf "select=gt(scene\,0.4),scale=320:-1" \
  -frames:v 1 -q:v 3 best_thumb.jpg

# 跳过片头和片尾各 10%，取中间段最佳帧
DURATION=$(ffprobe -v error -show_entries format=duration -of csv=p=0 video.mp4)
START=$(echo "$DURATION * 0.1" | bc)
END=$(echo "$DURATION * 0.9" | bc)
ffmpeg -ss "$START" -to "$END" -i video.mp4 \
  -vf "select=gt(scene\,0.3),scale=320:-1" \
  -frames:v 1 -q:v 3 smart_thumb.jpg
```

## 3. 等时间间隔批量截图

### 3.1 按帧率截图

```bash
# 每秒 1 张（fps=1）
ffmpeg -i video.mp4 -vf "fps=1" -q:v 5 frames/frame_%04d.jpg

# 每 10 秒 1 张（fps=1/10）
ffmpeg -i video.mp4 -vf "fps=1/10" -q:v 5 frames/frame_%04d.jpg

# 每 30 秒 1 张（用于长视频进度条预览）
ffmpeg -i video.mp4 -vf "fps=1/30,scale=160:-1" -q:v 20 previews/prev_%04d.jpg
```

### 3.2 指定时间段内批量截图

```bash
# 仅截图 30s~90s 之间
ffmpeg -ss 30 -to 90 -i video.mp4 \
  -vf "fps=1,scale=320:-1" \
  -q:v 5 frames/frame_%04d.jpg

# 截图并同时保存时间戳（通过文件名）
ffmpeg -i video.mp4 \
  -vf "fps=1/10,scale=320:-1,drawtext=fontsize=12:fontcolor=white:text='%{pts\:hms}':x=5:y=5" \
  -q:v 8 timestamped/frame_%04d.jpg
```

### 3.3 精确时间点批量截图

```bash
# 截取指定的多个时间点（用 select 滤镜 + eq）
ffmpeg -i video.mp4 \
  -vf "select='eq(t\,5)+eq(t\,30)+eq(t\,60)+eq(t\,90)',scale=320:-1" \
  -vsync vfr -q:v 3 frames/frame_%04d.jpg

# -vsync vfr：可变帧率输出（避免补帧）
```

## 4. 关键帧提取

### 4.1 原理：跳过非关键帧

```
普通解码：I─B─B─P─B─B─P─B─B─I
              ↑ 每帧都解码，速度慢

关键帧模式：I─────────────────I
              ↑ 只解码 I 帧，速度可达 10x
              适合内容审核/快速预览生成
```

### 4.2 提取所有关键帧

```bash
# select 滤镜过滤 I 帧，-skip_frame noref 跳过解码 P/B 帧
ffmpeg -skip_frame noref -i video.mp4 \
  -vf "select='eq(pict_type\,I)',scale=320:-1" \
  -vsync vfr -q:v 5 keyframes/key_%04d.jpg

# -skip_frame noref：不解码非参考帧（P/B 帧），大幅提升速度
# -vsync vfr：可变帧率，避免补空帧
```

### 4.3 查看关键帧时间点

```bash
# 列出所有关键帧的时间戳（秒）
ffprobe -v error -select_streams v:0 \
  -show_entries packet=pts_time,flags \
  -of csv=p=0 video.mp4 | grep "K"

# 输出示例：
# 0.000000,K_
# 2.000000,K_
# 4.000000,K_
# ...（每个 GOP 一行）

# 只输出关键帧时间（去掉 flags 列）
ffprobe -v error -select_streams v:0 \
  -show_entries packet=pts_time,flags \
  -of csv=p=0 video.mp4 | awk -F, '$2~/K/{print $1}'
```

### 4.4 每个关键帧 GOP 一张截图

```bash
# 按 GOP 间隔取截图（关键帧处 + 往后 1 秒）
ffmpeg -i video.mp4 \
  -vf "select='eq(pict_type\,I)',scale=320:-1" \
  -vsync vfr -q:v 5 \
  -frames:v 50 \
  keyframes/key_%04d.jpg

echo "共提取关键帧："
ls keyframes/ | wc -l
```

## 5. 视频雪碧图

### 5.1 什么是雪碧图

```
雪碧图（Sprite Sheet）= 多张缩略图拼成一张大图

原理：
  frame_001.jpg  frame_002.jpg  frame_003.jpg
  frame_004.jpg  frame_005.jpg  frame_006.jpg   → 合并为一张图
  frame_007.jpg  frame_008.jpg  frame_009.jpg      160x90, 3列3行

浏览器/播放器只需 1 次 HTTP 请求就能加载所有缩略图
用 CSS background-position 定位到具体帧

用途：视频播放器进度条 hover 预览
     ↑ 鼠标悬停进度条显示对应时刻的缩略图
```

### 5.2 生成雪碧图

```bash
# 步骤 1：每 10 秒截一张 160x90 的缩略图
mkdir -p /tmp/sprite_frames
ffmpeg -i video.mp4 \
  -vf "fps=1/10,scale=160:90:force_original_aspect_ratio=decrease,pad=160:90:(ow-iw)/2:(oh-ih)/2" \
  -q:v 20 /tmp/sprite_frames/frame_%04d.jpg

FRAME_COUNT=$(ls /tmp/sprite_frames/*.jpg | wc -l)
echo "共 $FRAME_COUNT 帧"

# 步骤 2：用 tile 滤镜拼合（每行 10 张）
COLS=10
ffmpeg -i "/tmp/sprite_frames/frame_%04d.jpg" \
  -vf "tile=${COLS}x0" \
  -q:v 10 sprite.jpg
# tile=10x0：每行 10 张，行数自动计算（0=自动）

# 清理临时帧
rm -rf /tmp/sprite_frames
```

### 5.3 生成配套的 VTT 文件（播放器用）

```bash
# 自动生成 WebVTT 索引文件（告诉播放器每帧对应的时间段和坐标）
#!/bin/bash
INTERVAL=10     # 每 10 秒一帧
COLS=10         # 雪碧图每行 10 张
THUMB_W=160     # 缩略图宽度
THUMB_H=90      # 缩略图高度
SPRITE_URL="sprite.jpg"

DURATION=$(ffprobe -v error -show_entries format=duration -of csv=p=0 video.mp4 | cut -d. -f1)

echo "WEBVTT" > thumbnails.vtt
echo "" >> thumbnails.vtt

idx=0
t=0
while [ $t -lt $DURATION ]; do
    end=$((t + INTERVAL))
    [ $end -gt $DURATION ] && end=$DURATION

    # 计算在雪碧图中的坐标
    col=$((idx % COLS))
    row=$((idx / COLS))
    x=$((col * THUMB_W))
    y=$((row * THUMB_H))

    # 格式化时间为 HH:MM:SS.000
    format_time() {
        local secs=$1
        printf "%02d:%02d:%02d.000" $((secs/3600)) $(((secs%3600)/60)) $((secs%60))
    }

    echo "$(format_time $t) --> $(format_time $end)" >> thumbnails.vtt
    echo "${SPRITE_URL}#xywh=${x},${y},${THUMB_W},${THUMB_H}" >> thumbnails.vtt
    echo "" >> thumbnails.vtt

    idx=$((idx + 1))
    t=$((t + INTERVAL))
done

echo "生成完成: thumbnails.vtt ($idx 条记录)"
```

### 5.4 单命令生成雪碧图（无需临时文件）

```bash
# 直接从视频生成雪碧图（一步完成）
ffmpeg -i video.mp4 \
  -vf "fps=1/10,scale=160:90:force_original_aspect_ratio=decrease,pad=160:90:(ow-iw)/2:(oh-ih)/2,tile=10x10" \
  -frames:v 1 -q:v 10 sprite.jpg

# tile=10x10：最多 100 张（超出会生成 sprite_002.jpg 等，需 %d 占位符）
# 长视频生成多张雪碧图：
ffmpeg -i video.mp4 \
  -vf "fps=1/10,scale=160:90,tile=10x10" \
  -q:v 10 sprite_%03d.jpg
```

### 5.5 雪碧图参数选型

| 视频时长 | 截图间隔 | 缩略图尺寸 | 布局 | 雪碧图数量 |
|----------|----------|------------|------|------------|
| < 5 分钟 | 5s | 160x90 | 10x6 | 1 张 |
| 5-30 分钟 | 10s | 160x90 | 10x18 | 1-2 张 |
| 30-120 分钟 | 30s | 120x68 | 10x24 | 1-2 张 |
| > 2 小时 | 60s | 120x68 | 10x12 | 多张 |

**权衡**：间隔越小预览越精细，但雪碧图体积越大（影响加载速度）。

## 6. GIF 动图生成

### 6.1 简单 GIF（质量较差）

```bash
# 最简方式（颜色失真明显）
ffmpeg -ss 10 -t 5 -i video.mp4 \
  -vf "fps=10,scale=320:-1" \
  output.gif
```

### 6.2 高质量 GIF（双 pass palette）

GIF 只支持 256 色，需要先分析视频生成最优调色板：

```bash
# Pass 1：生成调色板
ffmpeg -ss 10 -t 5 -i video.mp4 \
  -vf "fps=10,scale=320:-1:flags=lanczos,palettegen=stats_mode=diff" \
  -y palette.png

# Pass 2：用调色板生成 GIF
ffmpeg -ss 10 -t 5 -i video.mp4 -i palette.png \
  -lavfi "fps=10,scale=320:-1:flags=lanczos[x];[x][1:v]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" \
  -y output_hq.gif

rm palette.png
```

**一行完成（filter_complex 内联 palettegen）**：

```bash
ffmpeg -ss 10 -t 5 -i video.mp4 \
  -filter_complex "fps=10,scale=320:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=200[p];[s1][p]paletteuse=dither=bayer:bayer_scale=5" \
  -y output_hq.gif
```

### 6.3 GIF 参数调优

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `fps` | 帧率（越高越流畅但体积大） | 10-15 |
| `scale` | 宽度（高度用 -1 自动） | 320 / 480 |
| `flags=lanczos` | 缩放算法（质量最好） | `lanczos` |
| `max_colors` | 调色板颜色数（≤256） | 200-256 |
| `stats_mode` | 调色板统计模式 | `diff`（动态场景）/ `full`（静态） |
| `dither` | 抖动算法 | `bayer`（体积小）/ `sierra2_4a`（质量好）|
| `bayer_scale` | Bayer 抖动强度（0-5） | 5（噪点最少） |

```bash
# 极致压缩（体积优先）
ffmpeg -ss 10 -t 3 -i video.mp4 \
  -filter_complex "fps=8,scale=240:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=128[p];[s1][p]paletteuse=dither=bayer:bayer_scale=5" \
  -y small.gif

# 高质量（质量优先）
ffmpeg -ss 10 -t 5 -i video.mp4 \
  -filter_complex "fps=15,scale=480:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=256:stats_mode=diff[p];[s1][p]paletteuse=dither=sierra2_4a" \
  -y hq.gif
```

### 6.4 WebP 动图（更优选择）

```bash
# 动态 WebP：同等质量下体积比 GIF 小 50-70%
ffmpeg -ss 10 -t 5 -i video.mp4 \
  -vf "fps=15,scale=480:-1:flags=lanczos" \
  -loop 0 -compression_level 6 -q:v 70 \
  output.webp

# 参数说明：
# -loop 0        无限循环
# -q:v 0-100     质量（越高越好）
# -compression_level 0-6  压缩级别（越高越慢但体积小）
```

## 7. Go 实现：缩略图服务

### 7.1 截图配置结构

```go
package thumbnail

import (
	"context"
	"fmt"
	"os"
	"os/exec"
	"path/filepath"
	"strconv"
	"strings"
	"sync"
	"time"
)

// ScreenshotConfig 截图配置
type ScreenshotConfig struct {
	VideoPath  string        // 输入视频路径
	OutputPath string        // 输出文件路径（单张截图）
	SeekTime   time.Duration // 截图时间点
	Width      int           // 输出宽度（0=原始宽度）
	Height     int           // 输出高度（-1=按比例）
	Quality    int           // JPEG 质量 1-31（越小越好）
}

// SpriteConfig 雪碧图配置
type SpriteConfig struct {
	VideoPath  string // 输入视频路径
	OutputPath string // 雪碧图输出路径（支持 %03d 占位符）
	Interval   int    // 截图间隔（秒）
	ThumbW     int    // 单张缩略图宽度
	ThumbH     int    // 单张缩略图高度
	Cols       int    // 雪碧图每行张数
	Rows       int    // 雪碧图每列张数（0=自动）
	Quality    int    // JPEG 质量
}

// GIFConfig GIF 配置
type GIFConfig struct {
	VideoPath  string        // 输入视频路径
	OutputPath string        // 输出 GIF 路径
	StartTime  time.Duration // 起始时间
	Duration   time.Duration // GIF 时长
	Width      int           // 宽度（高度自动）
	FPS        int           // GIF 帧率
	MaxColors  int           // 调色板颜色数（≤256）
	HighQuality bool         // 是否使用高质量（双 pass palette）
}

// ThumbnailService 缩略图服务
type ThumbnailService struct {
	ffmpegPath  string
	concurrency int
	sem         chan struct{} // 并发限制信号量
}

// NewThumbnailService 创建服务
func NewThumbnailService(ffmpegPath string, concurrency int) *ThumbnailService {
	if ffmpegPath == "" {
		ffmpegPath = "ffmpeg"
	}
	if concurrency <= 0 {
		concurrency = 4
	}
	return &ThumbnailService{
		ffmpegPath:  ffmpegPath,
		concurrency: concurrency,
		sem:         make(chan struct{}, concurrency),
	}
}
```

### 7.2 截图方法

```go
// Screenshot 提取单帧截图
func (s *ThumbnailService) Screenshot(ctx context.Context, cfg ScreenshotConfig) error {
	args := []string{
		"-ss", formatSecs(cfg.SeekTime),
		"-i", cfg.VideoPath,
		"-frames:v", "1",
	}

	if cfg.Width > 0 || cfg.Height != 0 {
		h := cfg.Height
		if h == 0 {
			h = -1 // 按比例
		}
		w := cfg.Width
		if w == 0 {
			w = -1
		}
		args = append(args, "-vf", fmt.Sprintf("scale=%d:%d", w, h))
	}

	q := cfg.Quality
	if q <= 0 {
		q = 3 // 默认高质量
	}
	args = append(args, "-q:v", strconv.Itoa(q), "-y", cfg.OutputPath)

	cmd := exec.CommandContext(ctx, s.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("截图失败: %w\noutput: %s", err, string(out))
	}
	return nil
}

// BatchScreenshot 并发批量截图（多个视频同时处理）
func (s *ThumbnailService) BatchScreenshot(ctx context.Context, cfgs []ScreenshotConfig) []error {
	errs := make([]error, len(cfgs))
	var wg sync.WaitGroup

	for i, cfg := range cfgs {
		wg.Add(1)
		go func(idx int, c ScreenshotConfig) {
			defer wg.Done()
			// 获取信号量（限制并发数）
			select {
			case s.sem <- struct{}{}:
				defer func() { <-s.sem }()
			case <-ctx.Done():
				errs[idx] = ctx.Err()
				return
			}
			errs[idx] = s.Screenshot(ctx, c)
		}(i, cfg)
	}
	wg.Wait()
	return errs
}

// formatSecs 将 time.Duration 转为 FFmpeg 秒数字符串
func formatSecs(d time.Duration) string {
	return fmt.Sprintf("%.3f", d.Seconds())
}
```

### 7.3 雪碧图生成

```go
// GenerateSprite 生成视频雪碧图（含 VTT 索引）
func (s *ThumbnailService) GenerateSprite(ctx context.Context, cfg SpriteConfig) error {
	// 获取视频时长
	duration, err := getVideoDuration(s.ffmpegPath, cfg.VideoPath)
	if err != nil {
		return fmt.Errorf("获取视频时长失败: %w", err)
	}

	tileLayout := fmt.Sprintf("%dx%d", cfg.Cols, cfg.Rows)

	scaleFilter := fmt.Sprintf(
		"fps=1/%d,scale=%d:%d:force_original_aspect_ratio=decrease,pad=%d:%d:(ow-iw)/2:(oh-ih)/2",
		cfg.Interval, cfg.ThumbW, cfg.ThumbH, cfg.ThumbW, cfg.ThumbH)
	tileFilter := fmt.Sprintf("tile=%s", tileLayout)
	vf := scaleFilter + "," + tileFilter

	q := cfg.Quality
	if q <= 0 {
		q = 15
	}

	args := []string{
		"-i", cfg.VideoPath,
		"-vf", vf,
		"-q:v", strconv.Itoa(q),
		"-y", cfg.OutputPath,
	}

	cmd := exec.CommandContext(ctx, s.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("生成雪碧图失败: %w\noutput: %s", err, string(out))
	}

	// 生成配套 VTT 文件
	vttPath := strings.TrimSuffix(cfg.OutputPath, filepath.Ext(cfg.OutputPath)) + ".vtt"
	return generateVTT(vttPath, cfg.OutputPath, duration, cfg.Interval, cfg.ThumbW, cfg.ThumbH, cfg.Cols)
}

// getVideoDuration 获取视频时长（秒）
func getVideoDuration(ffprobePath, videoPath string) (float64, error) {
	if ffprobePath == "" || ffprobePath == "ffmpeg" {
		ffprobePath = "ffprobe"
	}
	cmd := exec.Command(ffprobePath, "-v", "error",
		"-show_entries", "format=duration",
		"-of", "csv=p=0", videoPath)
	out, err := cmd.Output()
	if err != nil {
		return 0, err
	}
	return strconv.ParseFloat(strings.TrimSpace(string(out)), 64)
}

// generateVTT 生成 WebVTT 雪碧图索引
func generateVTT(vttPath, spritePath string, duration float64, interval, thumbW, thumbH, cols int) error {
	var sb strings.Builder
	sb.WriteString("WEBVTT\n\n")

	spriteFile := filepath.Base(spritePath)
	idx := 0
	for t := 0; float64(t) < duration; t += interval {
		end := t + interval
		if float64(end) > duration {
			end = int(duration)
		}
		col := idx % cols
		row := idx / cols
		x := col * thumbW
		y := row * thumbH
		sb.WriteString(fmt.Sprintf("%s --> %s\n%s#xywh=%d,%d,%d,%d\n\n",
			formatVTTTime(t), formatVTTTime(end),
			spriteFile, x, y, thumbW, thumbH))
		idx++
	}

	return os.WriteFile(vttPath, []byte(sb.String()), 0o644)
}

func formatVTTTime(secs int) string {
	h := secs / 3600
	m := (secs % 3600) / 60
	s := secs % 60
	return fmt.Sprintf("%02d:%02d:%02d.000", h, m, s)
}
```

```go
// GenerateGIF 生成高质量 GIF 动图
func (s *ThumbnailService) GenerateGIF(ctx context.Context, cfg GIFConfig) error {
	fps := cfg.FPS
	if fps <= 0 {
		fps = 10
	}
	w := cfg.Width
	if w <= 0 {
		w = 320
	}
	maxColors := cfg.MaxColors
	if maxColors <= 0 || maxColors > 256 {
		maxColors = 200
	}

	startStr := formatSecs(cfg.StartTime)
	durStr := formatSecs(cfg.Duration)

	if !cfg.HighQuality {
		// 简单模式
		args := []string{
			"-ss", startStr, "-t", durStr, "-i", cfg.VideoPath,
			"-vf", fmt.Sprintf("fps=%d,scale=%d:-1:flags=lanczos", fps, w),
			"-y", cfg.OutputPath,
		}
		cmd := exec.CommandContext(ctx, s.ffmpegPath, args...)
		if out, err := cmd.CombinedOutput(); err != nil {
			return fmt.Errorf("生成 GIF 失败: %w\noutput: %s", err, string(out))
		}
		return nil
	}

	// 高质量双 pass 模式（filter_complex 内联 palettegen）
	filterComplex := fmt.Sprintf(
		"fps=%d,scale=%d:-1:flags=lanczos,split[s0][s1];[s0]palettegen=max_colors=%d:stats_mode=diff[p];[s1][p]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle",
		fps, w, maxColors)

	args := []string{
		"-ss", startStr, "-t", durStr, "-i", cfg.VideoPath,
		"-filter_complex", filterComplex,
		"-y", cfg.OutputPath,
	}

	cmd := exec.CommandContext(ctx, s.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("生成高质量 GIF 失败: %w\noutput: %s", err, string(out))
	}
	return nil
}
```

### 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 截图全黑 | 时间点超出视频时长 | `ffprobe` 先查时长 |
| 截图失败：Non full-range YUV | limited-range YUV 源与 MJPEG full-range 不兼容 | 加 `-pix_fmt yuvj420p`（推荐）或 `-strict unofficial` |
| 截图偏绿/色彩异常 | 其他颜色空间问题 | 尝试 `-vf format=yuv420p` 或检查源视频编码 |
| 雪碧图不完整（最后行空白）| tile 自动补空 | 正常现象，VTT 只记录有内容的格子 |
| GIF 色彩失真 | 未用 palette 模式 | 使用双 pass palettegen/paletteuse |
| GIF 体积过大 | fps 或尺寸过大 | 降低 fps（8-10）、缩减宽度（320以下）|
| 关键帧提取结果很少 | GOP 间隔大 | 正常，GOP=2~10s，每 GOP 一个关键帧 |

## 9. 本章总结

### 核心要点

1. **截图精度**：`-frames:v 1` 取单帧；`-vf fps=1/10` 批量等间隔；`select=pict_type=I` 只取关键帧（10x 速度）
2. **雪碧图流程**：fps 滤镜抽帧 → scale 统一尺寸 → tile 拼图 → 生成 VTT 索引
3. **GIF 必须用 palette**：`palettegen` + `paletteuse` 双 pass 方案是唯一获得良好色彩的方法
4. **WebP 比 GIF 更优**：同质量下体积减小 50-70%，现代浏览器全支持，优先考虑
5. **并发截图用信号量限制**：FFmpeg 本身是 CPU 密集型，并发数不宜超过 CPU 核数

### 截图场景速查

| 需求 | 命令要点 |
|------|----------|
| 视频封面（单张） | `-ss 5 -frames:v 1 -q:v 2` |
| 批量等间隔截图 | `-vf fps=1/10 -q:v 5` |
| 关键帧批量提取 | `-skip_frame noref -vf select=pict_type=I` |
| 进度条雪碧图 | `fps + scale + tile` + VTT |
| 高质量 GIF | `split → palettegen → paletteuse` |
| 动态 WebP | `-loop 0 -compression_level 6` |

| 术语 | 英文 | 解释 |
|------|------|------|
| 关键帧 | I-frame / Keyframe | 独立编码的完整画面帧，无需依赖其他帧解码 |

| paletteuse | - | GIF 调色板应用滤镜，配合 palettegen 使用 |
