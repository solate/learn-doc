# 模块 5：高级主题

> 字幕水印、拼接剪辑、截图缩略图——内容加工场景的实用技术。

## 本模块目标

- 掌握字幕的提取、嵌入、格式转换，理解硬字幕与软字幕的取舍
- 学会用 drawtext / overlay 做动态水印与文字标注
- 掌握视频拼接的三种方式及各自适用边界
- 学会精确裁剪、转场效果与变速处理
- 掌握截图、雪碧图、GIF/WebP 动图的生成与优化
