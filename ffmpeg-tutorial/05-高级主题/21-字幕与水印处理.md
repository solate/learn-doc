## 前置依赖说明

### 必需的 FFmpeg 编译选项

本章节的字幕和水印功能依赖以下 FFmpeg 编译选项：

| 功能 | 依赖库 | 编译选项 | 用途 |
|------|--------|----------|------|
| **硬字幕烧录** | libass | `--enable-libass` | `subtitles` 和 `ass` 滤镜 |
| **文字水印** | libfreetype | `--enable-libfreetype` | `drawtext` 滤镜 |
| **图片水印** | 无（内置） | - | `overlay` 滤镜 |
| **软字幕封装** | 无（内置） | - | 容器复用，不涉及滤镜 |

### 检查当前 FFmpeg 是否支持

```bash
# 检查是否支持字幕烧录
ffmpeg -filters 2>&1 | grep -E "subtitles|ass"

# 检查是否支持文字水印
ffmpeg -filters 2>&1 | grep drawtext

# 如果以上命令无输出，说明你的 FFmpeg 缺少必要的编译选项
```

## 1. 字幕系统原理

### 1.1 硬字幕 vs 软字幕

```
硬字幕（Hard Subtitle / Burned-in）：
  ┌─────────────────────────────┐
  │  视频帧（像素）              │
  │  ┌───────────────────────┐  │
  │  │ 这是字幕文字（已合并） │  │  ← 字幕像素已写入视频帧
  │  └───────────────────────┘  │    无法关闭，不可切换
  └─────────────────────────────┘

软字幕（Soft Subtitle / Muxed）：
  ┌──────────────────────────────────────┐
  │  MKV / MP4 容器                       │
  │  ├── 视频流 (h264)                    │
  │  ├── 音频流 (aac)                     │
  │  ├── 字幕流 0: 中文 (SRT/ASS)         │  ← 独立字幕轨道
  │  └── 字幕流 1: English (SRT/ASS)      │    播放器控制显示/切换
  └──────────────────────────────────────┘
```

| 对比项 | 硬字幕 | 软字幕 |
|--------|--------|--------|
| 兼容性 | 所有设备/平台 | 需要播放器支持 |
| 可切换 | ❌ 不可关闭 | ✅ 多语言切换 |
| 文件大小 | 略增（视频重编码） | 仅增加字幕轨道体积 |
| 画质影响 | 需重编码可能降质 | ✅ 视频流无损 |
| 适用场景 | 短视频/社交媒体分发 | 电影/剧集点播 |

### 1.2 常见字幕格式

```
SRT（最简单）：
  1
  00:00:01,000 --> 00:00:04,000
  Hello, this is a subtitle.

  2
  00:00:05,500 --> 00:00:08,000
  第二行字幕内容。

ASS/SSA（最强大）：
  [Script Info]
  ScriptType: v4.00+
  PlayResX: 1920
  PlayResY: 1080

  [V4+ Styles]
  Style: Default,Arial,48,&H00FFFFFF,&H000000FF,&H00000000,&H80000000,-1,0,0,0,100,100,0,0,1,2,2,2,10,10,10,0

  [Events]
  Dialogue: 0,0:00:01.00,0:00:04.00,Default,,0,0,0,,Hello {\c&H0000FF&}colorful{\r} subtitle!
```

| 格式 | 扩展名 | 特点 | 支持样式 |
|------|--------|------|----------|
| SubRip | .srt | 最通用，纯文本 | ❌ 仅简单 HTML 标签 |
| ASS/SSA | .ass/.ssa | 功能最强，支持特效 | ✅ 字体/颜色/位置/动画 |
| WebVTT | .vtt | HLS/Web 标准 | ⚠️ 有限 CSS 支持 |
| MOV_TEXT | 内嵌 | MP4 原生字幕格式 | ❌ 样式极少 |
| PGS | .sup | 蓝光图形字幕（位图） | 图片形式，无法编辑 |

### 1.3 字幕处理路径

```
硬字幕（需重编码视频）：
输入视频 → 解码 → subtitles滤镜（叠加字幕像素）→ 重编码 → 输出
                        ↑
                    字幕文件 .srt/.ass

软字幕（无需重编码）：
输入视频 ─┐
输入字幕 ─┴→ 复用器(mux) → 输出（-c copy -c:s mov_text）
```

## 2. 硬字幕烧录

### 2.1 基础 SRT 烧录

```bash
# 最简单的硬字幕烧录
ffmpeg -i input.mp4 -vf "subtitles=sub.srt" -c:a copy output.mp4

# 指定字体和大小（force_style 覆盖默认样式）
ffmpeg -i input.mp4 \
  -vf "subtitles=sub.srt:force_style='FontName=Microsoft YaHei,FontSize=28,PrimaryColour=&H00FFFFFF,OutlineColour=&H80000000,Outline=2'" \
  -c:v libx264 -preset medium -crf 20 \
  -c:a copy output.mp4
```

**force_style 常用参数**：

| 参数 | 说明 | 示例值 |
|------|------|--------|
| FontName | 字体名称（系统需安装） | `Microsoft YaHei` / `Noto Sans CJK SC` |
| FontSize | 字号（相对 PlayResY） | `24` / `28` / `36` |
| PrimaryColour | 主文字颜色（&HAABBGGRR）| `&H00FFFFFF`（白） |
| OutlineColour | 描边颜色 | `&H80000000`（半透明黑） |
| Outline | 描边宽度 | `1` / `2` / `3` |
| Shadow | 阴影偏移 | `0` / `1` |
| Bold | 粗体 | `-1`（开）/ `0`（关） |
| Alignment | 对齐（小键盘方位） | `2`（底部居中）/ `8`（顶部居中） |
| MarginV | 垂直边距（像素） | `20` / `40` |

### 2.2 颜色格式说明（重要陷阱）

ASS 颜色是 **BGR** 顺序，且带 Alpha 前缀，与 Web 的 RGB 相反：

```
格式：&HAABBGGRR
      ││ ││ ││ └─ Red   (红)
      ││ ││ └──── Green (绿)
      ││ └─────── Blue  (蓝)
      └────────── Alpha (00=不透明, FF=全透明)

示例：
  白色不透明 → &H00FFFFFF
  纯红色     → &H000000FF  （注意：不是 &H00FF0000！）
  纯蓝色     → &H00FF0000
  黄色       → &H0000FFFF
  半透明黑   → &H80000000
```

### 2.3 中文字体处理

```bash
# 查看系统可用字体（macOS/Linux）
fc-list :lang=zh | head -20

# 常见中文字体名称
# macOS:   PingFang SC / Hiragino Sans GB / STHeiti
# Linux:   Noto Sans CJK SC / WenQuanYi Micro Hei / Source Han Sans CN
# Windows: Microsoft YaHei / SimHei / SimSun

# 用指定字体目录（字体未安装时）
ffmpeg -i input.mp4 \
  -vf "subtitles=sub.srt:fontsdir=/usr/share/fonts/custom:force_style='FontName=SourceHanSansCN-Bold'" \
  -c:a copy output.mp4
```

### 2.4 从视频内嵌字幕烧录

```bash
# 1. 查看视频内的字幕流
ffprobe -v error -select_streams s -show_entries stream=index,codec_name:stream_tags=language \
  -of csv=p=0 movie.mkv
# 输出：2,subrip,chi
#      3,subrip,eng

# 2. 烧录第一条字幕流（si=0 表示第 0 条字幕，非全局 stream index）
ffmpeg -i movie.mkv -vf "subtitles=movie.mkv:si=0" \
  -c:v libx264 -crf 20 -c:a copy output.mp4

# 3. 烧录英文字幕（si=1）
ffmpeg -i movie.mkv -vf "subtitles=movie.mkv:si=1" \
  -c:v libx264 -crf 20 -c:a copy output_en.mp4
```

## 3. ASS/SSA 高级样式

### 3.1 生成 ASS 模板

```bash
# 先把 SRT 转 ASS，再手动调整样式
ffmpeg -i subtitle.srt subtitle.ass

# 生成的 subtitle.ass 结构：
# [Script Info]        → 全局参数（分辨率、帧率）
# [V4+ Styles]         → 样式定义（类似 CSS class）
# [Events]             → 对话行（Dialogue）
```

### 3.2 多样式定义

```ass
[Script Info]
ScriptType: v4.00+
WrapStyle: 0
ScaledBorderAndShadow: yes
PlayResX: 1920
PlayResY: 1080

[V4+ Styles]
; 格式说明（一行不换行，这里拆开仅供阅读）
; Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour,
; Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle,
; Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding
Format: Name, Fontname, Fontsize, PrimaryColour, SecondaryColour, OutlineColour, BackColour, Bold, Italic, Underline, StrikeOut, ScaleX, ScaleY, Spacing, Angle, BorderStyle, Outline, Shadow, Alignment, MarginL, MarginR, MarginV, Encoding

; 白色字幕（底部居中，标准字幕）
Style: Default,Noto Sans CJK SC,52,&H00FFFFFF,&H000000FF,&H00000000,&H80000000,-1,0,0,0,100,100,0,0,1,3,1,2,30,30,20,1

; 黄色字幕（顶部，翻译注释）
Style: TopNote,Noto Sans CJK SC,36,&H0000FFFF,&H000000FF,&H00000000,&H00000000,0,0,0,0,100,100,0,0,1,2,0,8,30,30,15,1

; 红色强调
Style: Emphasis,Noto Sans CJK SC,52,&H000000FF,&H000000FF,&H00000000,&H00000000,-1,0,0,0,100,100,0,0,1,3,1,2,30,30,20,1

[Events]
Format: Layer, Start, End, Style, Name, MarginL, MarginR, MarginV, Effect, Text
; 默认白色字幕
Dialogue: 0,0:00:01.00,0:00:04.00,Default,,0,0,0,,这是一句普通字幕
; 顶部黄色注释
Dialogue: 0,0:00:01.00,0:00:04.00,TopNote,,0,0,0,,（注：原文为英语）
; 行内样式覆盖（临时变红色）
Dialogue: 0,0:00:05.00,0:00:08.00,Default,,0,0,0,,这是{\c&H000000FF&\b1}重要{\r}内容
```

### 3.3 ASS 行内标签速查

```
{\b1}     粗体开启     {\b0}  粗体关闭
{\i1}     斜体开启     {\i0}  斜体关闭
{\u1}     下划线       {\s1}  删除线
{\fsFontSize} 字号，如 {\fs36}
{\c&H颜色&}   主色，如 {\c&H0000FF&} 变红色
{\3c&H颜色&}  描边色
{\alpha&H80&} 整体透明度（00=不透明）
{\an9}    位置（小键盘方位：1=左下 5=居中 9=右上）
{\pos(x,y)}   绝对坐标定位，如 {\pos(960,540)}
{\move(x1,y1,x2,y2,t1,t2)} 移动动画
{\fade(a1,a2,a3,t1,t2,t3)} 淡入淡出
{\r}      重置为 Style 默认值
{\rStyle} 切换为另一个 Style
```

```bash
# 应用 ASS 字幕（自动识别格式）
ffmpeg -i input.mp4 -vf "ass=subtitle.ass" -c:a copy output.mp4
```

## 4. 软字幕封装

### 4.1 MKV 多字幕封装

```bash
# 封装视频 + 多语言字幕到 MKV
ffmpeg -i video.mp4 \
  -i subtitle_zh.srt \
  -i subtitle_en.srt \
  -map 0:v -map 0:a \
  -map 1:0 -map 2:0 \
  -c:v copy -c:a copy \
  -c:s srt \
  -metadata:s:s:0 language=chi -metadata:s:s:0 title="中文字幕" \
  -metadata:s:s:1 language=eng -metadata:s:s:1 title="English" \
  output.mkv
```

### 4.2 MP4 字幕封装（mov_text）

```bash
# MP4 只支持 mov_text 格式（原生）或 SRT 转换
ffmpeg -i video.mp4 -i subtitle.srt \
  -map 0 -map 1 \
  -c:v copy -c:a copy \
  -c:s mov_text \
  -metadata:s:s:0 language=chi \
  output.mp4
```

### 4.3 HLS 外挂 WebVTT 字幕

```bash
# SRT 转 WebVTT
ffmpeg -i subtitle_zh.srt subtitle_zh.vtt
ffmpeg -i subtitle_en.srt subtitle_en.vtt

# m3u8 主播放列表引用字幕轨（需手动编辑 m3u8）
```

## 5. 图片水印

### 5.1 overlay 滤镜原理

```
overlay(x, y) 把第二路视频流叠加到第一路：

输入1（主视频）：1920×1080
                 ┌─────────────────────────────────┐
输入2（水印PNG）:│                    ┌──────────┐  │
  200×60         │                    │ LOGO.png │  │
                 │                    │(x=1680,  │  │
                 │                    │ y=20)    │  │
                 │                    └──────────┘  │
                 └─────────────────────────────────┘
```

**位置表达式**（支持数学表达式）：

| 位置 | x 表达式 | y 表达式 |
|------|----------|----------|
| 左上角 | `10` | `10` |
| 右上角 | `main_w-overlay_w-10` | `10` |
| 左下角 | `10` | `main_h-overlay_h-10` |
| 右下角 | `main_w-overlay_w-10` | `main_h-overlay_h-10` |
| 正中央 | `(main_w-overlay_w)/2` | `(main_h-overlay_h)/2` |

### 5.2 静态 PNG 水印（带透明通道）

```bash
# 右下角水印，距边缘 20px
ffmpeg -i input.mp4 -i logo.png \
  -filter_complex "overlay=main_w-overlay_w-20:main_h-overlay_h-20" \
  -c:a copy output.mp4

# 调整水印透明度（format=rgba 确保 alpha 通道）
ffmpeg -i input.mp4 -i logo.png \
  -filter_complex "[1:v]format=rgba,colorchannelmixer=aa=0.5[logo];[0:v][logo]overlay=main_w-overlay_w-20:main_h-overlay_h-20" \
  -c:a copy output.mp4

# 水印缩放到视频宽度的 15%（响应式大小）
ffmpeg -i input.mp4 -i logo.png \
  -filter_complex "[1:v]scale=iw*main_w/100*0.15:-1[logo];[0:v][logo]overlay=main_w-overlay_w-20:main_h-overlay_h-20" \
  -c:a copy output.mp4
```

### 5.3 平铺水印（防盗版）

```bash
# 水印平铺覆盖整个画面
ffmpeg -i input.mp4 -i watermark.png \
  -filter_complex "[1:v]tile=6x4[tiled];[0:v][tiled]overlay=0:0:shortest=1" \
  -c:a copy output.mp4
```

### 5.4 定时显示水印（仅在特定时间段）

```bash
# 仅在 5s~15s 显示水印
ffmpeg -i input.mp4 -i logo.png \
  -filter_complex "overlay=main_w-overlay_w-20:main_h-overlay_h-20:enable='between(t,5,15)'" \
  -c:a copy output.mp4
```

## 6. 动态文字水印

### 6.1 drawtext 滤镜基础

```bash
# 静态文字水印（版权声明）
ffmpeg -i input.mp4 \
  -vf "drawtext=fontfile=/usr/share/fonts/truetype/liberation/LiberationSans-Regular.ttf:
       text='© 2026 Example Corp':
       fontsize=36:
       fontcolor=white@0.7:
       x=main_w-text_w-20:
       y=main_h-text_h-20" \
  -c:a copy output.mp4
```

### 6.2 动态时间戳水印

```bash
# 在视频上叠加实时系统时间（用于监控录像）
ffmpeg -i rtsp://camera/stream \
  -vf "drawtext=fontfile=/path/to/font.ttf:
       text='%{localtime\:%Y-%m-%d %H\:%M\:%S}':
       fontsize=28:
       fontcolor=yellow:
       box=1:boxcolor=black@0.4:boxborderw=6:
       x=10:y=10" \
  -c:v libx264 -preset veryfast \
  -c:a copy /var/record/%Y%m%d_%H%M%S.mp4
```

**注意**：在 shell 中 `:` 需要转义为 `\:`（在 -vf 字符串内部）

### 6.3 视频帧时间码水印

```bash
# 显示视频播放时间（非系统时间），适合后期审阅
ffmpeg -i input.mp4 \
  -vf "drawtext=fontfile=/path/to/font.ttf:
       text='TC\: %{pts\:hms}':
       fontsize=24:
       fontcolor=white:
       box=1:boxcolor=black@0.5:boxborderw=4:
       x=(main_w-text_w)/2:y=main_h-text_h-30" \
  -c:a copy output_timecode.mp4
```

### 6.4 滚动字幕（跑马灯效果）

```bash
# 文字从右向左滚动（10s 滚过整个画面）
ffmpeg -i input.mp4 \
  -vf "drawtext=fontfile=/path/to/font.ttf:
       text='本视频受版权保护，禁止转载  |  版权所有 © 2026 Example Corp':
       fontsize=32:
       fontcolor=white@0.8:
       x='main_w - (t/10)*main_w':
       y=main_h-text_h-20" \
  -c:a copy output.mp4

# 精确控制滚动速度（像素/秒）
SPEED=200  # 200px/s
ffmpeg -i input.mp4 \
  -vf "drawtext=fontfile=/path/to/font.ttf:
       text='滚动版权声明文字':
       fontsize=30:fontcolor=white@0.7:
       x=main_w-t*$SPEED:y=main_h-50" \
  -c:a copy output_scroll.mp4
```

## 7. 复杂 overlay 滤镜

### 7.1 filter_complex 图结构

多路输入需要用 `-filter_complex` 而非 `-vf`：

```
-filter_complex 的流标签语法：
  [0:v]  → 第 0 个输入的视频流
  [1:v]  → 第 1 个输入的视频流
  [tmp]  → 自定义中间标签（任意名字）
  [out]  → 最终输出标签

示例：主视频 + 水印 + 字幕三路合并
```

### 8.3 SRT 时间轴调整

```bash

cat > adjust_subtitle.py << 'EOPY'
import sys
from datetime import timedelta

def parse_time(s):
    """解析 SRT 时间格式 00:00:01,000"""
    h, m, rest = s.split(':')
    s, ms = rest.split(',')
    return timedelta(hours=int(h), minutes=int(m), seconds=int(s), milliseconds=int(ms))

def format_time(td):
    """格式化为 SRT 时间"""
    total_seconds = int(td.total_seconds())
    hours = total_seconds // 3600
    minutes = (total_seconds % 3600) // 60
    seconds = total_seconds % 60
    milliseconds = td.microseconds // 1000
    return f"{hours:02d}:{minutes:02d}:{seconds:02d},{milliseconds:03d}"

def adjust_srt(input_file, output_file, offset_seconds):
    offset = timedelta(seconds=offset_seconds)
    with open(input_file, 'r', encoding='utf-8') as f_in, \
         open(output_file, 'w', encoding='utf-8') as f_out:
        for line in f_in:
            if '-->' in line:
                start, end = line.split('-->')
                start_time = parse_time(start.strip()) + offset
                end_time = parse_time(end.strip()) + offset
                f_out.write(f"{format_time(start_time)} --> {format_time(end_time)}\n")
            else:
                f_out.write(line)

if __name__ == '__main__':
    adjust_srt('subtitle.srt', 'subtitle_adjusted.srt', offset_seconds=2.5)
    print("字幕时间轴调整完成：所有字幕延迟 2.5 秒")
EOPY

python adjust_subtitle.py
```

```bash
def check_overlap(srt_file):
    import re
    with open(srt_file, 'r', encoding='utf-8') as f:
        lines = f.readlines()
    
    times = []
    for line in lines:
        if '-->' in line:
            match = re.search(r'(\d{2}:\d{2}:\d{2},\d{3}) --> (\d{2}:\d{2}:\d{2},\d{3})', line)
            if match:
                times.append((match.group(1), match.group(2)))
    
    for i in range(len(times) - 1):
        current_end = times[i][1]
        next_start = times[i+1][0]
        if current_end > next_start:
            print(f"⚠️  字幕 {i+1} 和 {i+2} 时间重叠：{current_end} > {next_start}")
    
    print(f"✓ 检查完成，共 {len(times)} 条字幕")
```

```bash
def merge_srt(zh_file, en_file, output_file):
    def parse_srt(file):
        with open(file, 'r', encoding='utf-8') as f:
            content = f.read()
        blocks = content.strip().split('\n\n')

        for block in blocks:

            f.write(f"{zh['time']}\n")
            f.write(f"{zh['text']}\n")

    print(f"✓ 双语字幕合并完成：{len(zh_subs)} 条")
```

### 8.1 水印配置结构

```go
package watermark

import (
	"context"
	"fmt"
	"os/exec"
	"path/filepath"
	"strings"
)

// WatermarkType 水印类型
type WatermarkType string

const (
	WatermarkTypeImage WatermarkType = "image"  // 图片水印
	WatermarkTypeText  WatermarkType = "text"   // 文字水印
)

// Position 水印位置
type Position string

const (
	PositionTopLeft     Position = "top_left"
	PositionTopRight    Position = "top_right"
	PositionBottomLeft  Position = "bottom_left"
	PositionBottomRight Position = "bottom_right"
	PositionCenter      Position = "center"
)

// WatermarkConfig 水印配置
type WatermarkConfig struct {
	Type     WatermarkType
	Position Position
	MarginX  int     // 水印距边缘 X 方向距离（像素）
	MarginY  int     // 水印距边缘 Y 方向距离（像素）
	Opacity  float64 // 透明度 0.0-1.0

	// 图片水印
	ImagePath  string
	ImageScale float64 // 相对视频宽度的比例（0.1 = 10%）

	// 文字水印
	Text      string
	FontPath  string
	FontSize  int
	FontColor string // 如 "white" 或 "#FFFFFF"
}

// positionToFFmpegExpr 将位置枚举转换为 FFmpeg overlay 表达式
func positionToFFmpegExpr(pos Position, marginX, marginY int) (x, y string) {
	mx, my := fmt.Sprintf("%d", marginX), fmt.Sprintf("%d", marginY)
	switch pos {
	case PositionTopLeft:
		return mx, my
	case PositionTopRight:
		return fmt.Sprintf("main_w-overlay_w-%s", mx), my
	case PositionBottomLeft:
		return mx, fmt.Sprintf("main_h-overlay_h-%s", my)
	case PositionBottomRight:
		return fmt.Sprintf("main_w-overlay_w-%s", mx), fmt.Sprintf("main_h-overlay_h-%s", my)
	case PositionCenter:
		return "(main_w-overlay_w)/2", "(main_h-overlay_h)/2"
	default:
		return mx, my
	}
}
```

### 8.2 水印处理器

```go
// WatermarkProcessor 水印处理器
type WatermarkProcessor struct {
	ffmpegPath string
}

// NewWatermarkProcessor 创建处理器
func NewWatermarkProcessor(ffmpegPath string) *WatermarkProcessor {
	if ffmpegPath == "" {
		ffmpegPath = "ffmpeg"
	}
	return &WatermarkProcessor{ffmpegPath: ffmpegPath}
}

// AddImageWatermark 添加图片水印
func (p *WatermarkProcessor) AddImageWatermark(ctx context.Context, inputPath, outputPath string, cfg WatermarkConfig) error {
	x, y := positionToFFmpegExpr(cfg.Position, cfg.MarginX, cfg.MarginY)

	filterParts := []string{}
	// 图片缩放（如果配置了相对大小）
	if cfg.ImageScale > 0 {
		filterParts = append(filterParts,
			fmt.Sprintf("[1:v]scale=iw*%.2f:-1[scaled]", cfg.ImageScale*float64(1920)/float64(100)))
	}
	// 透明度
	alphaTag := "1:v"
	if len(filterParts) > 0 {
		alphaTag = "scaled"
	}
	if cfg.Opacity > 0 && cfg.Opacity < 1.0 {
		filterParts = append(filterParts,
			fmt.Sprintf("[%s]format=rgba,colorchannelmixer=aa=%.1f[logo]", alphaTag, cfg.Opacity))
		alphaTag = "logo"
	}

	// overlay
	filterParts = append(filterParts,
		fmt.Sprintf("[0:v][%s]overlay=%s:%s", alphaTag, x, y))

	filterComplex := strings.Join(filterParts, ";")

	args := []string{
		"-i", inputPath,
		"-i", cfg.ImagePath,
		"-filter_complex", filterComplex,
		"-c:v", "libx264", "-preset", "veryfast", "-crf", "20",
		"-c:a", "copy",
		"-y", outputPath,
	}

	cmd := exec.CommandContext(ctx, p.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("添加图片水印失败: %w\noutput: %s", err, string(out))
	}
	return nil
}

// AddTextWatermark 添加文字水印
func (p *WatermarkProcessor) AddTextWatermark(ctx context.Context, inputPath, outputPath string, cfg WatermarkConfig) error {
	x, y := positionToFFmpegExpr(cfg.Position, cfg.MarginX, cfg.MarginY)
	// 文字宽高参与位置计算，需要替换 overlay_w/h 为 text_w/h
	x = strings.ReplaceAll(x, "overlay_w", "text_w")
	x = strings.ReplaceAll(x, "overlay_h", "text_h")
	y = strings.ReplaceAll(y, "overlay_w", "text_w")
	y = strings.ReplaceAll(y, "overlay_h", "text_h")

	color := cfg.FontColor
	if cfg.Opacity < 1.0 && cfg.Opacity > 0 {
		color = fmt.Sprintf("%s@%.1f", color, cfg.Opacity)
	}

	drawtextFilter := fmt.Sprintf(
		"drawtext=fontfile=%s:text='%s':fontsize=%d:fontcolor=%s:x=%s:y=%s:box=1:boxcolor=black@0.3:boxborderw=4",
		cfg.FontPath, cfg.Text, cfg.FontSize, color, x, y,
	)

	args := []string{
		"-i", inputPath,
		"-vf", drawtextFilter,
		"-c:v", "libx264", "-preset", "veryfast", "-crf", "20",
		"-c:a", "copy",
		"-y", outputPath,
	}

	cmd := exec.CommandContext(ctx, p.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("添加文字水印失败: %w\noutput: %s", err, string(out))
	}
	return nil
}
```

### 8.3 字幕处理器

```go
// SubtitleConfig 字幕配置
type SubtitleConfig struct {
	SubtitlePath string // SRT / ASS 文件路径
	FontName     string // 字体名称
	FontSize     int    // 字号
	FontColor    string // 颜色（ASS 格式 &HAABBGGRR）
	Outline      int    // 描边宽度
	MarginV      int    // 垂直边距
	Hard         bool   // true=硬字幕, false=软字幕（封装）
}

// SubtitleProcessor 字幕处理器
type SubtitleProcessor struct {
	ffmpegPath string
}

func NewSubtitleProcessor(ffmpegPath string) *SubtitleProcessor {
	return &SubtitleProcessor{ffmpegPath: ffmpegPath}
}

// BurnSubtitle 烧录硬字幕
func (p *SubtitleProcessor) BurnSubtitle(ctx context.Context, inputPath, outputPath string, cfg SubtitleConfig) error {
	ext := strings.ToLower(filepath.Ext(cfg.SubtitlePath))
	var vf string
	if ext == ".ass" || ext == ".ssa" {
		vf = fmt.Sprintf("ass=%s", cfg.SubtitlePath)
	} else {
		// SRT：用 force_style 自定义样式
		forceStyle := fmt.Sprintf("FontName=%s,FontSize=%d,PrimaryColour=%s,Outline=%d,MarginV=%d",
			cfg.FontName, cfg.FontSize, cfg.FontColor, cfg.Outline, cfg.MarginV)
		vf = fmt.Sprintf("subtitles=%s:force_style='%s'", cfg.SubtitlePath, forceStyle)
	}

	args := []string{
		"-i", inputPath,
		"-vf", vf,
		"-c:v", "libx264", "-preset", "medium", "-crf", "20",
		"-c:a", "copy",
		"-y", outputPath,
	}

	cmd := exec.CommandContext(ctx, p.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("烧录字幕失败: %w\noutput: %s", err, string(out))
	}
	return nil
}

// MuxSubtitle 封装软字幕（MKV）
func (p *SubtitleProcessor) MuxSubtitle(ctx context.Context, inputPath, subtitlePath, lang, outputPath string) error {
	args := []string{
		"-i", inputPath,
		"-i", subtitlePath,
		"-map", "0", "-map", "1",
		"-c:v", "copy", "-c:a", "copy",
		"-c:s", "srt",
		fmt.Sprintf("-metadata:s:s:0"), fmt.Sprintf("language=%s", lang),
		"-y", outputPath,
	}

	cmd := exec.CommandContext(ctx, p.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("封装字幕失败: %w\noutput: %s", err, string(out))
	}
	return nil
}
```

```go
	filterParts := []string{}

	// 水印透明度
	if watermarkCfg.Opacity > 0 && watermarkCfg.Opacity < 1.0 {
		filterParts = append(filterParts,
			fmt.Sprintf("[1:v]format=rgba,colorchannelmixer=aa=%.1f[logo]", watermarkCfg.Opacity))
	} else {
		filterParts = append(filterParts, "[1:v]format=rgba[logo]")
	}

	// 水印 overlay
	filterParts = append(filterParts,
		fmt.Sprintf("[0:v][logo]overlay=%s:%s[watermarked]", x, y))

	// 字幕烧录
	ext := strings.ToLower(filepath.Ext(subtitleCfg.SubtitlePath))
	if ext == ".ass" || ext == ".ssa" {
		filterParts = append(filterParts,
			fmt.Sprintf("[watermarked]ass=%s[out]", subtitleCfg.SubtitlePath))
	} else {
		forceStyle := fmt.Sprintf("FontName=%s,FontSize=%d,PrimaryColour=%s,Outline=%d,MarginV=%d",
			subtitleCfg.FontName, subtitleCfg.FontSize, subtitleCfg.FontColor, subtitleCfg.Outline, subtitleCfg.MarginV)
		filterParts = append(filterParts,
			fmt.Sprintf("[watermarked]subtitles=%s:force_style='%s'[out]", subtitleCfg.SubtitlePath, forceStyle))
	}

	filterComplex := strings.Join(filterParts, ";")

	args := []string{
		"-i", inputPath,
		"-i", watermarkCfg.ImagePath,
		"-filter_complex", filterComplex,
		"-map", "[out]", "-map", "0:a",
		"-c:v", "libx264", "-preset", "medium", "-crf", "20",
		"-c:a", "copy",
		"-y", outputPath,
	}

	cmd := exec.CommandContext(ctx, p.ffmpegPath, args...)
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("组合处理失败: %w\noutput: %s", err, string(out))
	}
	return nil
}
```

### 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 字幕显示 `?????` 乱码 | 字幕文件编码不是 UTF-8 | `iconv -f GBK -t UTF-8 sub.srt > sub_utf8.srt` |
| 字幕找不到中文字体 | 系统未安装中文字体 | 安装 `fonts-noto-cjk` 或指定 `fontsdir` |
| 水印透明度不生效 | 输入 PNG 无 Alpha 通道 | 用 GIMP/ImageMagick 确保 PNG 是 RGBA 模式 |
| overlay 报错 `not same size` | 两路输入分辨率不一致 | 在 filter_complex 中先用 `scale` 统一尺寸 |
| ASS 颜色显示为白色 | BGR 顺序写错 | 检查颜色格式：`&HAABBGGRR`（非 RGB！）|
| drawtext 冒号报错 | shell 中 `:` 未转义 | `-vf` 内部用 `\:` 代替 `:` |
| SRT 时间轴不同步 | 字幕偏移或视频剪辑后未调整 | 用 Python 脚本批量调整时间戳 |
| 软字幕在 MP4 中无法显示 | 播放器不支持 mov_text | 改用 MKV 容器或烧录成硬字幕 |
| 双语字幕显示混乱 | 时间轴不对齐 | 用字幕编辑器（Aegisub）手动对齐 |
| ASS 字幕特效不生效 | 播放器不支持高级 ASS 标签 | 改用 VLC/mpv 播放或烧录成硬字幕 |
| 字幕文件 BOM 导致首行错误 | UTF-8 BOM 标记 | `sed '1s/^\xEF\xBB\xBF//' input.srt > output.srt` |

## 11. 本章总结

### 核心要点

1. **硬字幕 vs 软字幕选择**：社交媒体/分发用硬字幕（兼容性最强）；点播平台用软字幕（多语言切换）
2. **ASS 颜色是 BGR 顺序**：`&HAABBGGRR`，红色是 `&H000000FF` 而非 `&H00FF0000`
3. **中文字幕必须指定字体**：系统默认字体通常不含中文，需 `fontfile=` 或 `FontName=` 指定
4. **overlay 基于 filter_complex**：多路输入必须用 `-filter_complex`，使用标签 `[0:v][1:v]` 引用流
5. **drawtext 的动态变量**：`%{pts\:hms}` 显示时间码，`%{localtime\:...}` 显示系统时间
6. **位置计算用 main_w/main_h 表达式**：避免硬编码像素值，确保不同分辨率下水印位置正确

### 滤镜选择指南

| 需求 | 使用滤镜 | 关键参数 |
|------|----------|----------|
| SRT 烧录 | `subtitles` | `force_style=` 覆盖样式 |
| ASS 烧录 | `ass` | 直接读 ASS 文件样式 |
| 图片水印 | `overlay` | `x/y` 表达式定位 |
| 文字水印 | `drawtext` | `text=`, `fontfile=`, `x=`, `y=` |
| 调整透明度 | `colorchannelmixer=aa=0.7` | aa 控制 alpha 通道 |
| 画中画 | `scale` + `overlay` | 先缩放再 overlay |
| 多效果叠加 | `filter_complex` 链式 | `[tmp1]...[tmp2]...` 标签串联 |

## 12. 术语表

| 术语 | 英文 | 解释 |
|------|------|------|
| 硬字幕 | Hard Subtitle / Burned-in | 字幕像素烧录进视频帧，不可关闭 |
| 软字幕 | Soft Subtitle / Muxed | 独立字幕轨道，播放器控制显示 |
| ASS/SSA | Advanced SubStation Alpha | 功能最强的字幕格式，支持动画和复杂样式 |
| SRT | SubRip Text | 最简单的时序字幕格式 |
| WebVTT | Web Video Text Tracks | HLS/Web 平台标准字幕格式 |
| overlay | - | FFmpeg 滤镜，将第二路视频叠加到第一路 |
| drawtext | - | FFmpeg 滤镜，在视频帧上绘制文字 |
| subtitles | - | FFmpeg 滤镜，烧录 SRT/ASS 字幕到视频 |
| filter_complex | - | FFmpeg 多路输入/输出复杂滤镜图语法 |
| force_style | - | subtitles 滤镜的参数，覆盖字幕默认样式 |
| BGR | Blue-Green-Red | ASS 颜色格式（与 Web RGB 顺序相反）|
| alpha 通道 | Alpha Channel | 图像透明度信息，PNG 支持 RGBA 四通道 |
