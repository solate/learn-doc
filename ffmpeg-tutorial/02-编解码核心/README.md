# 模块 2：编解码核心

> 深入理解视频编解码原理，掌握主流编码器参数与技术选型。

## 本模块目标

- 精通 H.264/H.265/AV1 编码器的参数调优
- 理解 CRF/CBR/VBR 三种码率控制模式的适用场景
- 掌握音频编码和音频处理技术
- 学会配置 NVIDIA/Intel/Apple/AMD 硬件加速
- 建立视频质量评估体系，设计码率梯队
