# 模块 1：基础入门

> 从零开始理解 FFmpeg 的架构、安装、信息分析和命令语法。

## 本模块目标

- 理解 FFmpeg 的整体架构和核心库分工
- 掌握各平台的安装和验证方法
- 学会用 ffprobe 深度分析视频文件
- 完全掌握 FFmpeg 命令行语法规则
- 理解转封装（remux）和流复制的原理

## 学习建议

- **按顺序学习**：每篇依赖前序知识
- **动手实践**：每篇末尾都有实践环节，跟着做一遍
- **理解原理**：不要只记命令，要理解为什么这样写
- **建立索引**：遇到问题时能快速回来查阅

## 前置知识

- 了解基本的视频概念（分辨率、码率、帧率）
- 熟悉命令行操作
- 无需 FFmpeg 基础（从零开始）
