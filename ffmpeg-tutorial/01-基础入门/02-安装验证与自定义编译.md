## 各平台安装方式

### macOS

**方案 1：Homebrew（推荐，最简单）**

```bash
# 安装最新版 FFmpeg
brew install ffmpeg

# 查看可用的编译选项
brew info ffmpeg

# 带特定选项重新安装（如需要 libfdk-aac）
brew reinstall ffmpeg --with-fdk-aac
```

**优点**：
- 一键安装，自动处理依赖
- 默认包含大部分常用编解码器
- 自动更新

**缺点**：
- 不包含 nonfree 编解码器（如 libfdk-aac）
- 编译选项固定，定制性较差

---

**方案 2：静态编译版（完整功能）**

```bash
# 下载静态编译版（包含所有编解码器）
curl -O https://evermeet.cx/ffmpeg/ffmpeg-8.0.zip
unzip ffmpeg-8.0.zip
sudo mv ffmpeg /usr/local/bin/

# 验证
ffmpeg -version
```

**优点**：
- 包含所有编解码器（包括 nonfree）
- 无需依赖，单文件即可运行
- 适合生产环境部署

**缺点**：
- 文件体积大（100MB+）
- 需要手动更新

---

### Ubuntu/Debian

**方案 1：apt 源（最简单，但版本可能旧）**

```bash
# 更新包列表
sudo apt update

# 安装 FFmpeg
sudo apt install ffmpeg

# 查看版本
ffmpeg -version
```

**版本问题**：
- Ubuntu 20.04 LTS：FFmpeg 4.2（较旧）
- Ubuntu 22.04 LTS：FFmpeg 4.4
- Ubuntu 24.04 LTS：FFmpeg 6.0+

**如果版本太旧，使用下面的方案。**

---

**方案 2：PPA 源（较新版本）**

```bash
# 添加 PPA
sudo add-apt-repository ppa:savoury1/ffmpeg4
sudo apt update

# 安装 FFmpeg
sudo apt install ffmpeg

# 验证版本
ffmpeg -version
```

---

**方案 3：静态编译版（推荐生产环境）**

```bash
# 下载静态编译版
wget https://johnvansickle.com/ffmpeg/releases/ffmpeg-release-amd64-static.tar.xz

# 解压
tar xf ffmpeg-release-amd64-static.tar.xz

# 移动到系统路径
cd ffmpeg-*-static
sudo cp ffmpeg ffprobe /usr/local/bin/

# 验证
ffmpeg -version
```

**优点**：
- 版本最新（FFmpeg 8.0）
- 包含所有编解码器
- 无依赖冲突

---

**方案 4：从源码编译（最大定制性）**

```bash
# 安装编译依赖
sudo apt install -y \
  build-essential \
  yasm \
  nasm \
  pkg-config \
  libx264-dev \
  libx265-dev \
  libvpx-dev \
  libfdk-aac-dev \
  libmp3lame-dev \
  libopus-dev

# 下载源码
wget https://ffmpeg.org/releases/ffmpeg-8.0.tar.xz
tar xf ffmpeg-8.0.tar.xz
cd ffmpeg-8.0

# 配置编译选项
./configure \
  --prefix=/usr/local \
  --enable-gpl \
  --enable-nonfree \
  --enable-libx264 \
  --enable-libx265 \
  --enable-libvpx \
  --enable-libfdk-aac \
  --enable-libmp3lame \
  --enable-libopus

# 编译（利用多核，-j 后面是核心数）
make -j8

# 安装
sudo make install

# 验证
ffmpeg -version
```

**编译时间**：根据机器性能，10-30 分钟。

### Windows

**方案 1：Chocolatey 包管理器**

```powershell
# 安装 Chocolatey（如果还没有）
Set-ExecutionPolicy Bypass -Scope Process -Force
[System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# 安装 FFmpeg
choco install ffmpeg

# 验证
ffmpeg -version
```

---

**方案 2：Scoop 包管理器（推荐）**

```powershell
# 安装 Scoop（如果还没有）
iwr -useb get.scoop.sh | iex

# 安装 FFmpeg
scoop install ffmpeg

# 验证
ffmpeg -version
```

---

**方案 3：静态编译版（手动安装）**

1. 访问 https://www.gyan.dev/ffmpeg/builds/
2. 下载 `ffmpeg-release-essentials.zip`
3. 解压到 `C:\ffmpeg\`
4. 添加 `C:\ffmpeg\bin` 到系统环境变量 PATH
5. 打开新的命令行窗口，验证：

```cmd
ffmpeg -version
```

### Alpine Linux（Docker 最小镜像）

**Dockerfile 示例**：

```dockerfile
FROM alpine:3.18

# 安装 FFmpeg
RUN apk add --no-cache ffmpeg

# 验证
RUN ffmpeg -version

# 工作目录
WORKDIR /data

# 入口点
ENTRYPOINT ["ffmpeg"]
```

**构建并测试**：

```bash
# 构建镜像
docker build -t my-ffmpeg .

# 测试
docker run --rm my-ffmpeg -version
```

**镜像大小**：约 80MB（Alpine + FFmpeg）

## 官方 Docker 镜像选型

### 镜像对比

| 镜像 | 大小 | 特点 | 适用场景 |
|------|------|------|---------|
| `linuxserver/ffmpeg` | ~200MB | 完整功能，包含硬件加速 | 生产环境，需要硬件加速 |
| `jrottenberg/ffmpeg` | ~150MB | 多版本标签，定制性强 | 开发测试，版本对比 |
| `alpine:latest` + apk | ~80MB | 最小体积，基础功能 | 资源受限环境 |
| 自建静态编译版 | ~120MB | 完全可控，包含所有编解码器 | 生产部署，需要特定编解码器 |

---

### 推荐方案：jrottenberg/ffmpeg

```bash
# 拉取最新版本
docker pull jrottenberg/ffmpeg:8.0-alpine

# 测试运行
docker run --rm jrottenberg/ffmpeg:8.0-alpine -version

# 转码示例
docker run --rm -v $(pwd):/data \
  jrottenberg/ffmpeg:8.0-alpine \
  -i /data/input.mp4 -c:v libx264 -crf 23 /data/output.mp4
```

**标签说明**：
- `8.0-alpine`：基于 Alpine，体积小
- `8.0-ubuntu`：基于 Ubuntu，兼容性好
- `8.0-nvidia`：支持 NVENC 硬件加速
- `8.0-vaapi`：支持 VAAPI 硬件加速（Intel/AMD）

### 自建 Docker 镜像（生产推荐）

```dockerfile
FROM alpine:3.18 AS builder

# 安装编译依赖
RUN apk add --no-cache \
    build-base \
    yasm \
    nasm \
    pkgconf \
    x264-dev \
    x265-dev \
    libvpx-dev \
    opus-dev

# 下载 FFmpeg 源码
WORKDIR /tmp
RUN wget https://ffmpeg.org/releases/ffmpeg-8.0.tar.xz && \
    tar xf ffmpeg-8.0.tar.xz

# 编译 FFmpeg
WORKDIR /tmp/ffmpeg-8.0
RUN ./configure \
    --prefix=/usr/local \
    --enable-gpl \
    --enable-libx264 \
    --enable-libx265 \
    --enable-libvpx \
    --enable-libopus \
    --enable-small && \
    make -j$(nproc) && \
    make install

# 运行时镜像
FROM alpine:3.18

# 复制编译好的 FFmpeg
COPY --from=builder /usr/local/bin/ffmpeg /usr/local/bin/
COPY --from=builder /usr/local/bin/ffprobe /usr/local/bin/

# 安装运行时依赖
RUN apk add --no-cache \
    libx264 \
    libx265 \
    libvpx \
    opus

# 工作目录
WORKDIR /data

# 入口点
ENTRYPOINT ["ffmpeg"]
```

**构建**：

```bash
docker build -t custom-ffmpeg:8.0 .
```

**镜像大小**：约 50MB（多阶段构建优化）

## 编译选项解读

### 核心选项

```bash
./configure \
  --prefix=/usr/local              # 安装路径
  --enable-gpl                     # 启用 GPL 许可的库（x264/x265）
  --enable-nonfree                 # 启用 nonfree 库（libfdk-aac）
  --enable-libx264                 # H.264 软件编码器
  --enable-libx265                 # H.265 软件编码器
  --enable-libvpx                  # VP8/VP9 编码器
  --enable-libsvtav1               # AV1 编码器（Intel SVT）
  --enable-libfdk-aac              # 高质量 AAC 编码器（nonfree）
  --enable-libmp3lame              # MP3 编码器
  --enable-libopus                 # Opus 编码器
  --enable-libvorbis               # Vorbis 编码器
```

---

### 硬件加速选项

```bash
# NVIDIA NVENC（需要 CUDA SDK）
--enable-cuda-nvcc \
--enable-cuvid \
--enable-nvenc \
--enable-libnpp

# Intel QSV（需要 Intel Media SDK）
--enable-libmfx

# VAAPI（Linux 通用硬件加速）
--enable-vaapi

# VideoToolbox（macOS/iOS）
--enable-videotoolbox

# Vulkan（跨平台 GPU 计算）
--enable-vulkan \
--enable-libshaderc
```

---

### 协议支持

```bash
# 流媒体协议
--enable-protocol=rtmp           # RTMP 推拉流
--enable-protocol=rtsp           # RTSP 拉流
--enable-protocol=http           # HTTP/HTTPS
--enable-protocol=hls            # HLS 协议
--enable-libsrt                  # SRT 弱网传输
```

---

### 优化选项

```bash
--enable-small                   # 优化体积（减少二进制大小）
--enable-lto                     # 链接时优化（Link Time Optimization）
--enable-static                  # 静态链接（单文件部署）
--disable-debug                  # 禁用调试信息（减少体积）
--enable-stripping               # 剥离符号表（进一步减小体积）
```

---

### 查看当前编译选项

```bash

ffmpeg -version

# 示例输出：
# configuration: --prefix=/usr/local --enable-gpl --enable-libx264 --enable-libx265
```

```bash

```

```
configuration: --prefix=/usr/local --enable-gpl --enable-libx264 ...
```

**关键检查点**：
- 版本号：8.0 或更高
- 编译日期：确认是最新版本
- 配置选项：确认包含你需要的编解码器

### 2. 检查编码器支持

```bash
# 查看所有编码器
ffmpeg -encoders

# 检查特定编码器
ffmpeg -encoders | grep -E "264|265|av1|aac|opus"
```

**必须有的编码器**：

**可选但推荐的**：

### 完整验证脚本

```bash
#!/bin/bash

echo "=== FFmpeg 安装验证 ==="

# 1. 版本检查
echo "1. 检查版本..."
ffmpeg -version | head -1

# 2. 编码器检查
echo "2. 检查关键编码器..."
ffmpeg -encoders 2>/dev/null | grep -E "libx264|libx265|libsvtav1|aac" | wc -l
echo "   期望: 至少 2 个（libx264 和 aac）"

# 3. 硬件加速检查
echo "3. 检查硬件加速..."
ffmpeg -hwaccels 2>/dev/null | grep -v "Hardware" | wc -l
echo "   可用硬件加速方法数"

# 4. 协议检查
echo "4. 检查关键协议..."
ffmpeg -protocols 2>/dev/null | grep -E "rtmp|rtsp|http" | wc -l
echo "   期望: 至少 3 个（rtmp/rtsp/http）"

# 5. 功能测试
echo "5. 生成测试视频..."
ffmpeg -f lavfi -i testsrc=duration=2:size=640x480:rate=30 \
       -f lavfi -i sine=frequency=1000:duration=2 \
       -c:v libx264 -c:a aac -y test_verify.mp4 2>&1 | grep -q "muxing overhead"

if [ -f test_verify.mp4 ]; then
    echo "   ✅ 测试视频生成成功"
    rm test_verify.mp4
else
    echo "   ❌ 测试视频生成失败"
fi

echo "=== 验证完成 ==="
```

## 常见问题排查

### 问题 1：提示 "Unknown encoder 'libx264'"

**原因**：FFmpeg 编译时未包含 libx264

**解决方案**：
- macOS：`brew reinstall ffmpeg`
- Ubuntu：使用静态编译版或重新编译
- 检查：`ffmpeg -encoders | grep x264`

---

### 问题 2：硬件加速不可用

**检查步骤**：

```bash
# 1. 查看硬件加速列表
ffmpeg -hwaccels

# 2. 查看硬件编码器
ffmpeg -encoders | grep nvenc  # NVIDIA
ffmpeg -encoders | grep qsv    # Intel
ffmpeg -encoders | grep videotoolbox  # macOS
```

**常见原因**：
- 驱动未安装（NVIDIA 需要 CUDA 驱动）
- FFmpeg 编译时未启用硬件加速
- Docker 容器未挂载 GPU

**解决方案**：
```bash
# Docker 挂载 NVIDIA GPU
docker run --gpus all -v $(pwd):/data \
  jrottenberg/ffmpeg:8.0-nvidia \
  -hwaccel cuda -i /data/input.mp4 ...
```

---

### 问题 3：RTMP 协议不支持

**检查**：
```bash
ffmpeg -protocols | grep rtmp
```

**如果没有输出**，重新编译并启用：
```bash
./configure --enable-protocol=rtmp ...
```

---

### 问题 4：macOS 提示"无法验证开发者"

```bash
# 移除隔离属性
xattr -d com.apple.quarantine /usr/local/bin/ffmpeg
```

```bash
ffmpeg -f lavfi -i color=c=red:duration=5:size=1280x720 \
       -c:v libx264 red.mp4

# 带音频
ffmpeg -f lavfi -i testsrc=duration=5 \
       -f lavfi -i sine=frequency=1000:duration=5 \
       -c:v libx264 -c:a aac test_av.mp4
```

## 本篇小结

1. **安装方式选择**：
   - 开发测试：包管理器（brew/apt）
   - 生产部署：静态编译版或 Docker
   - 定制需求：从源码编译

2. **Docker 镜像**：推荐 `jrottenberg/ffmpeg:8.0-alpine`，体积小、功能全

3. **必须验证的项目**：版本、编码器、硬件加速、协议、功能测试

4. **测试素材**：用 `testsrc`/`color`/`sine` 生成，或下载 Big Buck Bunny

5. **常见问题**：编码器缺失、硬件加速不可用、协议不支持
