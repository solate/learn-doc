## 1. filter_complex 架构原理

### 1.1 filtergraph 概念

`-filter_complex` 是 FFmpeg 处理多输入/多输出流的核心机制。与 `-vf`（单视频流）和 `-af`（单音频流）不同，filtergraph 可以处理任意数量的输入输出流。

```
┌──────────────────────────────────────────────────────┐
│                   filter_complex                      │
│                                                       │
│  [0:v]──▶ scale ──▶ [small_v]─┐                      │
│                                ├──▶ hstack ──▶ [out] │
│  [1:v]──▶ scale ──▶ [big_v]──┘                       │
│                                                       │
└──────────────────────────────────────────────────────┘
```

### 1.2 与 -vf/-af 的区别

| 特性 | `-vf` / `-af` | `-filter_complex` |
|------|---------------|-------------------|
| 输入流数量 | 1 个 | 任意多个 |
| 输出流数量 | 1 个 | 任意多个 |
| 语法 | 简单链式 | 完整图语法 |
| 使用场景 | 单流处理 | 混流、合并、分叉 |

### 1.3 基本结构

```
[输入标签]滤镜名=参数[输出标签];[输入标签]滤镜名=参数[输出标签]
```

- **分号** `;`：分隔独立的滤镜链
- **逗号** `,`：同一链内串联多个滤镜
- **方括号标签** `[label]`：标识流，用于滤镜间连接

## 2. 标签语法与流引用

### 2.1 输入流标签

```bash
# 引用输入文件的流
[0:v]  # 第一个输入文件的视频流
[1:a]  # 第二个输入文件的音频流
[2:v:0] # 第三个输入文件的第一个视频流
```

### 2.2 自定义标签

```bash
# 标签命名规则
[mystream]   # ✅ 字母数字下划线
[video_1080] # ✅ 可读性强的命名
[0]          # ❌ 不要用纯数字（易与输入索引混淆）
```

### 2.3 未命名流的隐式连接

```bash
# 无标签版本（隐式连接）
ffmpeg -i input.mp4 -filter_complex "scale=640:360,fps=30" output.mp4

# 等价的显式标签版本
ffmpeg -i input.mp4 -filter_complex "[0:v]scale=640:360[scaled];[scaled]fps=30[out]" -map "[out]" output.mp4
```

### 2.4 多输入多输出示例

```bash
# 两路视频横向拼接
ffmpeg -i left.mp4 -i right.mp4 \
  -filter_complex "[0:v][1:v]hstack=inputs=2[out]" \
  -map "[out]" output.mp4
```

**原理**：
- `[0:v]` 和 `[1:v]` 作为 `hstack` 的输入
- `hstack` 生成的流命名为 `[out]`
- `-map "[out]"` 将输出流映射到文件

## 3. split/asplit：流复制与分叉

### 3.1 视频流分叉（split）

```bash
# 一路输入分成两路（一路缩小、一路保持原样）
ffmpeg -i input.mp4 \
  -filter_complex "[0:v]split=2[original][copy];\
                   [copy]scale=640:360[small]" \
  -map "[original]" full.mp4 \
  -map "[small]" small.mp4
```

**split 语法**：
```
[input]split=N[out1][out2]...[outN]
```

### 3.2 音频流分叉（asplit）

```bash
# 一路音频分成两路（一路降噪、一路原音）
ffmpeg -i input.mp3 \
  -filter_complex "[0:a]asplit=2[original][copy];\
                   [copy]afftdn=nr=20[denoised]" \
  -map "[original]" original.mp3 \
  -map "[denoised]" denoised.mp3
```

### 3.3 多路输出：一次输入生成多分辨率

```bash
# ABR 流媒体打包：生成 1080p/720p/480p 三路
ffmpeg -i input.mp4 \
  -filter_complex "\
    [0:v]split=3[v1][v2][v3];\
    [v1]scale=1920:1080[1080p];\
    [v2]scale=1280:720[720p];\
    [v3]scale=854:480[480p]" \
  -map "[1080p]" -c:v libx264 -b:v 5M -maxrate 5M -bufsize 10M 1080p.mp4 \
  -map "[720p]" -c:v libx264 -b:v 3M -maxrate 3M -bufsize 6M 720p.mp4 \
  -map "[480p]" -c:v libx264 -b:v 1.5M -maxrate 1.5M -bufsize 3M 480p.mp4
```

## 4. hstack/vstack：横纵拼接

### 4.1 hstack：横向拼接

```bash
# 两路视频左右并排（对比图）
ffmpeg -i original.mp4 -i processed.mp4 \
  -filter_complex "[0:v][1:v]hstack=inputs=2" \
  side_by_side.mp4

# 三路视频横排（需统一高度）
ffmpeg -i a.mp4 -i b.mp4 -i c.mp4 \
  -filter_complex "\
    [0:v]scale=-1:480[v1];\
    [1:v]scale=-1:480[v2];\
    [2:v]scale=-1:480[v3];\
    [v1][v2][v3]hstack=inputs=3[out]" \
  -map "[out]" triple.mp4
```

**注意**：`hstack` 要求所有输入的**高度相同**。用 `scale=-1:H` 统一高度，宽度自适应。

### 4.2 vstack：纵向拼接

```bash
# 两路视频上下叠放
ffmpeg -i top.mp4 -i bottom.mp4 \
  -filter_complex "\
    [0:v]scale=1280:-1[top];\
    [1:v]scale=1280:-1[bottom];\
    [top][bottom]vstack=inputs=2[out]" \
  -map "[out]" stacked.mp4
```

**注意**：`vstack` 要求所有输入的**宽度相同**。

### 4.3 尺寸不一致时的处理

```bash
# 用 pad 填充到相同尺寸，再拼接
ffmpeg -i wide.mp4 -i narrow.mp4 \
  -filter_complex "\
    [0:v]scale=1280:720[left];\
    [1:v]scale=640:720,pad=1280:720:320:0:black[right];\
    [left][right]hstack=inputs=2[out]" \
  -map "[out]" padded_side.mp4
```

## 5. xstack：N宫格布局

### 5.1 xstack 语法

```
xstack=inputs=N:layout=x0_y0|x1_y1|...|xN-1_yN-1
```

每个输入的左上角坐标由 `layout` 指定。

### 5.2 2x2 四宫格

```bash
# 四路视频 2×2 网格布局
ffmpeg -i cam1.mp4 -i cam2.mp4 -i cam3.mp4 -i cam4.mp4 \
  -filter_complex "\
    [0:v]scale=960:540[v1];\
    [1:v]scale=960:540[v2];\
    [2:v]scale=960:540[v3];\
    [3:v]scale=960:540[v4];\
    [v1][v2][v3][v4]xstack=inputs=4:layout=0_0|960_0|0_540|960_540[out]" \
  -map "[out]" grid_2x2.mp4
```

**布局说明**：
- `0_0`：左上角（cam1）
- `960_0`：右上角（cam2）
- `0_540`：左下角（cam3）
- `960_540`：右下角（cam4）

### 5.3 3x3 九宫格

```bash
ffmpeg -i 1.mp4 -i 2.mp4 -i 3.mp4 -i 4.mp4 -i 5.mp4 \
       -i 6.mp4 -i 7.mp4 -i 8.mp4 -i 9.mp4 \
  -filter_complex "\
    [0:v]scale=640:360[v1];[1:v]scale=640:360[v2];[2:v]scale=640:360[v3];\
    [3:v]scale=640:360[v4];[4:v]scale=640:360[v5];[5:v]scale=640:360[v6];\
    [6:v]scale=640:360[v7];[7:v]scale=640:360[v8];[8:v]scale=640:360[v9];\
    [v1][v2][v3][v4][v5][v6][v7][v8][v9]xstack=inputs=9:\
layout=0_0|640_0|1280_0|0_360|640_360|1280_360|0_720|640_720|1280_720[out]" \
  -map "[out]" grid_3x3.mp4
```

### 5.4 自定义布局（画中画）

```bash
# 主画面 + 右下角小画面
ffmpeg -i main.mp4 -i pip.mp4 \
  -filter_complex "\
    [0:v]scale=1920:1080[main];\
    [1:v]scale=480:270[pip];\
    [main][pip]xstack=inputs=2:layout=0_0|1440_810[out]" \
  -map "[out]" custom_layout.mp4
```

## 6. concat：时间轴拼接

### 6.1 基础拼接

```bash
# 三段视频顺序拼接
ffmpeg -i part1.mp4 -i part2.mp4 -i part3.mp4 \
  -filter_complex "[0:v][0:a][1:v][1:a][2:v][2:a]concat=n=3:v=1:a=1[outv][outa]" \
  -map "[outv]" -map "[outa]" merged.mp4
```

**参数说明**：
- `n=3`：拼接 3 个片段
- `v=1`：包含 1 路视频
- `a=1`：包含 1 路音频
- 输入顺序：`[v0][a0][v1][a1][v2][a2]`（视频音频交替）

### 6.2 concat 前必须统一参数

```bash
# 统一分辨率、帧率、像素格式后再拼接
ffmpeg -i raw1.mp4 -i raw2.mp4 \
  -filter_complex "\
    [0:v]scale=1280:720,fps=30,format=yuv420p[v1];\
    [1:v]scale=1280:720,fps=30,format=yuv420p[v2];\
    [0:a]aresample=44100[a1];\
    [1:a]aresample=44100[a2];\
    [v1][a1][v2][a2]concat=n=2:v=1:a=1[outv][outa]" \
  -map "[outv]" -map "[outa]" -c:v libx264 -c:a aac output.mp4
```

### 6.3 仅拼接视频（无音频）

```bash
ffmpeg -i clip1.mp4 -i clip2.mp4 -i clip3.mp4 \
  -filter_complex "[0:v][1:v][2:v]concat=n=3:v=1:a=0[outv]" \
  -map "[outv]" -an video_only.mp4
```

## 7. overlay：画中画与叠加

### 7.1 基础 overlay

```bash
# 右上角画中画
ffmpeg -i main.mp4 -i pip.mp4 \
  -filter_complex "\
    [1:v]scale=320:180[pip_scaled];\
    [0:v][pip_scaled]overlay=W-w-20:20[out]" \
  -map "[out]" -map 0:a pip.mp4
```

位置表达式：
- `W/H`：主视频宽/高
- `w/h`：覆盖视频宽/高
- `W-w-20:20`：右上角，距边缘 20px

### 7.2 时间控制 overlay

```bash
# 只在 10-20 秒显示 logo（enable 表达式）
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=10:10:enable='between(t,10,20)'" \
  output.mp4

# 动态移动水印（t=时间，从左到右）
ffmpeg -i video.mp4 -i watermark.png \
  -filter_complex "[0:v][1:v]overlay=x='t*50':y=10" \
  moving_watermark.mp4
```

### 7.3 overlay 与 alpha 通道

```bash
# PNG 水印（带透明度）直接叠加
ffmpeg -i video.mp4 -i watermark.png \
  -filter_complex "[0:v][1:v]overlay=W-w-10:H-h-10:alpha=1" \
  watermarked.mp4

# 调整水印透明度（format=argb 保留 alpha）
ffmpeg -i video.mp4 -i watermark.png \
  -filter_complex "[1:v]colorchannelmixer=aa=0.5[wm];\
                   [0:v][wm]overlay=W-w-10:H-h-10" \
  semi_transparent.mp4
```

## 8. 多路转码：一次输入多路输出

### 8.1 ABR 自适应码率转码

```bash
# 一次解码，生成 1080p/720p/480p 三路输出
ffmpeg -i input.mp4 \
  -filter_complex "\
    [0:v]split=3[v1][v2][v3];\
    [v1]scale=1920:1080[1080p];\
    [v2]scale=1280:720[720p];\
    [v3]scale=854:480[480p];\
    [0:a]asplit=3[a1][a2][a3]" \
  -map "[1080p]" -map "[a1]" -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 192k output_1080p.mp4 \
  -map "[720p]" -map "[a2]" -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 128k output_720p.mp4 \
  -map "[480p]" -map "[a3]" -c:v libx264 -preset medium -crf 23 -c:a aac -b:a 96k output_480p.mp4
```

**优势**：
- 只解码一次，节省 CPU
- 并行编码三路，比顺序编码快 2-3 倍

### 8.2 不同编解码器并行输出

```bash
# 同时生成 H.264 和 H.265
ffmpeg -i input.mp4 \
  -filter_complex "[0:v]split=2[v264][v265]" \
  -map "[v264]" -c:v libx264 -crf 23 output_h264.mp4 \
  -map "[v265]" -c:v libx265 -crf 28 output_h265.mp4
```

## 9. 音视频同步处理

### 9.1 setpts/asetpts 时间轴对齐

```bash
# 视频延迟 2 秒出现（音频立即开始）
ffmpeg -i input.mp4 \
  -filter_complex "[0:v]setpts=PTS+2/TB[v]" \
  -map "[v]" -map 0:a -c:v libx264 -c:a copy delayed_video.mp4
```

**时间基（TB）**：
- `PTS+2/TB`：当前时间戳加 2 秒（`TB` = 时间基倒数）
- `PTS-STARTPTS`：从 0 开始重置时间戳

### 9.2 混合音视频同步

```bash
# 视频 + 独立音轨（二者时长可能不同）
ffmpeg -i video.mp4 -i audio.mp3 \
  -filter_complex "\
    [0:v]setpts=PTS-STARTPTS[v];\
    [1:a]asetpts=PTS-STARTPTS[a]" \
  -map "[v]" -map "[a]" \
  -c:v copy -c:a aac -shortest sync.mp4
```

**-shortest**：以最短的流为准截断输出。

### 9.3 音视频合并时长对齐

```bash
# 视频 60 秒，音频 55 秒 → 末尾 5 秒静音补齐
ffmpeg -i video.mp4 -i audio.mp3 \
  -filter_complex "\
    [1:a]apad=whole_dur=60[padded_audio]" \
  -map 0:v -map "[padded_audio]" \
  -c:v copy -c:a aac aligned.mp4
```

## 10. 监控墙实战：4路/9路

### 10.1 4路监控墙（实时流）

```bash

    [3:v]scale=960:540,setpts=PTS-STARTPTS[v4];\
    [v1][v2][v3][v4]xstack=inputs=4:\
layout=0_0|960_0|0_540|960_540:shortest=1[out]" \
```

## 11. Go 集成：动态构建 filtergraph

### 11.1 xstack 布局计算器

```go
package filtergraph

import (
	"fmt"
	"strings"
)

// GridLayout 计算 N 宫格布局
type GridLayout struct {
	Cols      int
	Rows      int
	CellWidth int
	CellHeight int
}

// NewGridLayout 根据摄像头数量自动计算最优网格
func NewGridLayout(n, cellW, cellH int) GridLayout {
	cols := int(math.Ceil(math.Sqrt(float64(n))))
	rows := (n + cols - 1) / cols
	return GridLayout{Cols: cols, Rows: rows, CellWidth: cellW, CellHeight: cellH}
}

// XStackLayout 生成 xstack 的 layout 参数
func (g GridLayout) XStackLayout() string {
	positions := make([]string, g.Cols*g.Rows)
	for row := 0; row < g.Rows; row++ {
		for col := 0; col < g.Cols; col++ {
			x := col * g.CellWidth
			y := row * g.CellHeight
			positions[row*g.Cols+col] = fmt.Sprintf("%d_%d", x, y)
		}
	}
	return strings.Join(positions, "|")
}

// TotalWidth 输出总宽度
func (g GridLayout) TotalWidth() int { return g.Cols * g.CellWidth }

// TotalHeight 输出总高度
func (g GridLayout) TotalHeight() int { return g.Rows * g.CellHeight }
```

### 11.2 FilterGraph 构建器

```go
// FilterGraphBuilder 滤镜图构建器
type FilterGraphBuilder struct {
	chains []string
}

// AddChain 添加滤镜链
func (b *FilterGraphBuilder) AddChain(chain string) *FilterGraphBuilder {
	b.chains = append(b.chains, chain)
	return b
}

// Build 生成完整 filtergraph
func (b *FilterGraphBuilder) Build() string {
	return strings.Join(b.chains, ";")
}

// BuildMonitorWall 构建监控墙 filtergraph
func BuildMonitorWall(inputs []string, cellW, cellH int) (string, error) {
	if len(inputs) == 0 {
		return "", fmt.Errorf("至少需要 1 路输入")
	}
	
	layout := NewGridLayout(len(inputs), cellW, cellH)
	builder := &FilterGraphBuilder{}
	
	// 每路输入：scale + 添加标签
	labels := make([]string, len(inputs))
	for i := range inputs {
		labels[i] = fmt.Sprintf("[v%d]", i)
		chain := fmt.Sprintf("[%d:v]scale=%d:%d,drawtext=text='CAM%d':fontsize=32:fontcolor=white:x=10:y=10%s",
			i, cellW, cellH, i+1, labels[i])
		builder.AddChain(chain)
	}
	
	// xstack 拼接
	xstackChain := fmt.Sprintf("%sxstack=inputs=%d:layout=%s[out]",
		strings.Join(labels, ""), len(inputs), layout.XStackLayout())
	builder.AddChain(xstackChain)
	
	return builder.Build(), nil
}
```

### 11.3 多路转码服务

```go
// TranscodeProfile 转码规格
type TranscodeProfile struct {
	Name    string
	Width   int
	Height  int
	Bitrate string
	AudioBitrate string
}

// MultiTranscodeService 多路并行转码服务
type MultiTranscodeService struct{}

// Transcode 一次输入并行生成多路输出
func (s *MultiTranscodeService) Transcode(ctx context.Context, inputPath string, profiles []TranscodeProfile, outputDir string) error {
	if len(profiles) == 0 {
		return fmt.Errorf("至少需要一个转码规格")
	}
	
	// 构建 filter_complex
	splitFilter := fmt.Sprintf("[0:v]split=%d", len(profiles))
	labels := make([]string, len(profiles))
	for i := range profiles {
		labels[i] = fmt.Sprintf("[vsplit%d]", i)
	}
	splitFilter += strings.Join(labels, "")
	
	// 为每路生成 scale 滤镜
	scaleParts := make([]string, len(profiles))
	scaleLabels := make([]string, len(profiles))
	for i, p := range profiles {
		scaleLabels[i] = fmt.Sprintf("[v%d]", i)
		scaleParts[i] = fmt.Sprintf("[vsplit%d]scale=%d:%d%s", i, p.Width, p.Height, scaleLabels[i])
	}
	
	filterComplex := splitFilter + ";" + strings.Join(scaleParts, ";")
	
	// 构建 ffmpeg 参数
	args := []string{"-i", inputPath, "-filter_complex", filterComplex}
	
	for i, p := range profiles {
		outputPath := filepath.Join(outputDir, p.Name+".mp4")
		args = append(args,
			"-map", scaleLabels[i],
			"-map", "0:a",
			"-c:v", "libx264", "-b:v", p.Bitrate,
			"-c:a", "aac", "-b:a", p.AudioBitrate,
			outputPath,
		)
	}
	
	cmd := exec.CommandContext(ctx, "ffmpeg", args...)
	return cmd.Run()
}
```

## 13. 本章总结

本章覆盖了 `-filter_complex` 的完整使用场景：

| 场景 | 滤镜/方法 | 关键参数 |
|------|-----------|----------|
| 流复制分叉 | `split` / `asplit` | `n=N`（路数） |
| 横向拼接 | `hstack` | `inputs=N`（需统一高度） |
| 纵向拼接 | `vstack` | `inputs=N`（需统一宽度） |
| N宫格布局 | `xstack` | `inputs=N:layout=x_y\|...` |
| 时间轴拼接 | `concat` | `n=N:v=1:a=1`（交替流顺序） |
| 画中画叠加 | `overlay` | `x:y:enable='between(t,s,e)'` |
| 多路输出 | `split` + 多 `-map` | 一次解码多路编码 |
| 时间对齐 | `setpts` / `apad` | `PTS-STARTPTS` / `whole_dur` |

**关键原则**：
1. **标签命名清晰**：`[v1080p]` 优于 `[a]`，避免同名标签冲突
2. **concat 前统一格式**：scale/fps/format/aresample 必须一致，否则花屏
3. **xstack 坐标精确**：每个输入的坐标必须无缝衔接，否则黑边
4. **split 减少解码次数**：多路输出优先用 split 而非多次输入同一文件
5. **Go 构建 filtergraph** 时用数组拼接，禁止拼接用户输入（注入风险）
