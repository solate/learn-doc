## 1. 什么是滤镜系统

### 1.1 滤镜在管道中的位置

回顾 FFmpeg 处理管道（[第 1 篇](../01-基础入门/01-ffmpeg全景与架构解析.md)）：

```
输入文件 → 解封装 → 解码 → [滤镜处理] → 编码 → 封装 → 输出文件
                    ↓                ↑
                  原始帧          处理后的帧
              (像素/音频样本)
```

**滤镜处理的是原始帧数据**，而非压缩的编码数据：
```
输入：YUV 像素数组（视频）或 PCM 样本（音频）
输出：处理后的 YUV 或 PCM 数据

不能直接操作 H.264 码流 → 必须先解码 → 滤镜 → 再编码
```

---

### 1.2 为什么需要滤镜

```
场景 1：视频尺寸调整
  原始：4K (3840×2160) → 滤镜：scale=1920:1080 → 输出：1080p

场景 2：水印叠加
  视频流 + PNG 图片 → 滤镜：overlay → 输出：带水印视频

场景 3：音量归一化
  音频响度不均 → 滤镜：loudnorm → 输出：统一响度

场景 4：多画面拼接
  4 路视频 → 滤镜：xstack → 输出：2×2 网格画面
```

**核心价值**：滤镜系统提供了**像素级和样本级**的精细处理能力。

## 2. libavfilter 架构

### 2.1 核心概念

**libavfilter** 是 FFmpeg 的滤镜处理库，采用**图结构**（Filter Graph）组织滤镜。

```
滤镜图（Filter Graph）
  ├─ 源（Source）：输入数据
  ├─ 滤镜（Filter）：处理节点
  ├─ 缓冲（Buffer）：滤镜间传递数据
  └─ 汇（Sink）：输出数据
```

**处理流程**：
```
           ┌─────────────────────────────────────┐
           │         滤镜图（Filter Graph）       │
           │                                     │
输入流 ──→ [buffer] ──→ [scale] ──→ [overlay] ──→ [buffersink] ──→ 编码器
           │         ↓                 ↑         │
           │       1920×1080        水印PNG      │
           │                                     │
           └─────────────────────────────────────┘
```

---

### 2.2 三层结构

```
AVFilterGraph（图）
  │
  ├── AVFilterContext（滤镜实例）
  │     ├── AVFilter（滤镜定义）：scale, overlay, crop...
  │     └── AVFilterPad（输入/输出端口）
  │
  └── AVFilterLink（连接）：连接两个滤镜的输入/输出
```

**关系**：
```
AVFilter        滤镜蓝图（scale 的算法定义）
AVFilterContext 滤镜实例（具体的 scale=1280:720）
AVFilterGraph   滤镜图容器（管理所有实例和连接）
AVFilterLink    数据通道（传递帧数据）
```

---

### 2.3 执行模型

```
步骤 1：初始化滤镜图
  avfilter_graph_alloc()

步骤 2：创建滤镜实例
  avfilter_graph_create_filter() → scale, overlay...

步骤 3：连接滤镜
  avfilter_link() → 建立数据流向

步骤 4：配置图
  avfilter_graph_config() → 协商格式、分配内存

步骤 5：处理数据
  循环：av_buffersrc_add_frame() → av_buffersink_get_frame()
```

**命令行自动完成上述步骤**，我们只需编写滤镜表达式。

## 3. 三种滤镜命令

### 3.1 `-vf`（简单视频滤镜）

**适用场景**：单输入单输出的视频处理

```bash
# 缩放到 720p
ffmpeg -i input.mp4 -vf "scale=1280:720" output.mp4

# 多个滤镜串联（逗号分隔）
ffmpeg -i input.mp4 -vf "scale=1920:1080,unsharp=5:5:1.0" output.mp4
```

**等价于**：
```bash
-filter:v "scale=1280:720"
-filter_complex "[0:v]scale=1280:720[out]" -map "[out]"
```

---

### 3.2 `-af`（简单音频滤镜）

**适用场景**：单输入单输出的音频处理

```bash
# 音量调整为 50%
ffmpeg -i input.mp4 -af "volume=0.5" output.mp4

# 音频淡入（前 3 秒）
ffmpeg -i input.mp4 -af "afade=t=in:d=3" output.mp4

# 多个音频滤镜
ffmpeg -i input.mp4 -af "volume=1.5,loudnorm" output.mp4
```

---

### 3.3 `-filter_complex`（复杂滤镜图）

**适用场景**：多输入/多输出、分支/合并

```bash
# 画中画（两个输入）
ffmpeg -i main.mp4 -i small.mp4 \
  -filter_complex "[0:v][1:v]overlay=W-w-10:H-h-10[out]" \
  -map "[out]" output.mp4

# 分支处理（一个输入生成多个输出）
ffmpeg -i input.mp4 \
  -filter_complex "[0:v]split[a][b]; [a]scale=1920:1080[out1]; [b]scale=1280:720[out2]" \
  -map "[out1]" output_1080p.mp4 \
  -map "[out2]" output_720p.mp4
```

**必须使用 `-filter_complex` 的情况**：
```
1. 多个输入文件（overlay, concat）
2. 分支输出（split）
3. 音视频混合处理（amerge, concat）
4. 自定义标签引用
```

## 4. 滤镜链与滤镜图

### 4.1 滤镜链（Filter Chain）

**逗号分隔**，顺序执行，每个滤镜的输出是下一个滤镜的输入。

```bash
# 滤镜链示例：缩放 → 锐化 → 添加文字
ffmpeg -i input.mp4 \
  -vf "scale=1920:1080, unsharp=5:5:1.0, drawtext=text='Hello':x=10:y=10" \
  output.mp4
```

**执行顺序**：
```
原始帧(4K) → scale=1920:1080 → 1080p帧 → unsharp → 锐化帧 → drawtext → 最终帧
```

---

### 4.2 滤镜图（Filter Graph）

**分号分隔**，定义独立的处理路径，用标签连接。

```bash
# 滤镜图示例：分支生成两个输出
ffmpeg -i input.mp4 \
  -filter_complex "
    [0:v] split [a][b];
    [a] scale=1920:1080 [out_1080p];
    [b] scale=1280:720  [out_720p]
  " \
  -map "[out_1080p]" output_1080p.mp4 \
  -map "[out_720p]"  output_720p.mp4
```

**ASCII 流程图**：
```
                    ┌──→ scale=1920:1080 ──→ [out_1080p] → output_1080p.mp4
[0:v] ──→ split ──→┤
                    └──→ scale=1280:720  ──→ [out_720p]  → output_720p.mp4
```

---

### 4.3 逗号 vs 分号区别

```
逗号（,）：链式连接（Chain）
  - 上一滤镜的唯一输出 → 下一滤镜的唯一输入
  - 只有一个数据流通路
  - 简单场景专用

分号（;）：图结构连接（Graph）
  - 分隔独立的处理路径
  - 用标签 [...] 标记输入/输出端口
  - 支持多路并行、汇合、分支
```

**等价写法**：
```bash
# 这两个命令等价
ffmpeg -i input.mp4 -vf "scale=1280:720,unsharp" output.mp4

ffmpeg -i input.mp4 \
  -filter_complex "[0:v]scale=1280:720[s];[s]unsharp[out]" \
  -map "[out]" output.mp4
```

## 5. 标签与流引用

### 5.1 默认流引用

```bash
# 默认引用：[输入文件索引:流类型]
[0:v]   # 第1个输入文件的第1条视频流
[0:a]   # 第1个输入文件的第1条音频流
[1:v]   # 第2个输入文件的第1条视频流
[0:v:1] # 第1个输入文件的第2条视频流

# 示例：第2个输入的视频叠加在第1个输入上
ffmpeg -i background.mp4 -i overlay.mp4 \
  -filter_complex "[0:v][1:v]overlay=0:0" \
  output.mp4
```

---

### 5.2 自定义标签

```bash
# 标签格式：[任意字母数字字符串]
[scaled]   # 描述性标签
[out_1080] # 带分辨率标签
[temp]     # 临时中间标签

# 使用规则
# 1. 每个标签只能被写入（生产）一次
# 2. 每个标签可以被读取（消费）多次（通过 split）
# 3. 不匹配标签会报错 "output pad 'xxx' not connected"
```

**完整示例**：
```bash
ffmpeg -i main.mp4 -i watermark.png \
  -filter_complex "
    [0:v] scale=1920:1080 [main_scaled];
    [1:v] scale=200:100 [logo_scaled];
    [main_scaled][logo_scaled] overlay=W-w-20:H-h-20 [final]
  " \
  -map "[final]" -map 0:a \
  -c:a copy output.mp4
```

---

### 5.3 `-map` 指令

`-filter_complex` 产生的输出**必须用 `-map` 显式指定**要用哪个输出。

```bash
# 没有 -map：FFmpeg 自动选择（可能选错）
# 有 -map：精确控制哪路输出进入编码器

# 选择自定义标签
-map "[out]"

# 选择原始流（不经过滤镜）
-map 0:a   # 第1个输入的音频直通

# 多路输出
ffmpeg -i input.mp4 \
  -filter_complex "[0:v]split[a][b]" \
  -map "[a]" output_a.mp4 \
  -map "[b]" output_b.mp4
```

## 6. 分支与合并

### 6.1 分支（Split）

**场景**：一个输入生成多个独立的输出路径。

```bash
# split 滤镜：1 输入 → N 输出
ffmpeg -i input.mp4 \
  -filter_complex "
    [0:v] split=2 [a][b];
    [a] scale=1920:1080 [out1];
    [b] scale=1280:720  [out2]
  " \
  -map "[out1]" hd.mp4 \
  -map "[out2]" sd.mp4
```

**split 参数**：
```
split       # 默认分2路
split=3     # 分3路（需要3个输出标签）
split=4     # 分4路
```

**音频分支**：
```bash
# asplit：音频分支
ffmpeg -i input.mp3 \
  -filter_complex "
    [0:a] asplit=2 [a][b];
    [a] volume=0.5 [out1];
    [b] volume=2.0 [out2]
  " \
  -map "[out1]" quiet.mp3 \
  -map "[out2]" loud.mp3
```

---

### 6.2 合并（Overlay / Concat）

**overlay（叠加）**：两个视频流空间叠加
```bash
# 基础叠加：主画面 + 水印
ffmpeg -i main.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=10:10" \
  output.mp4

# 指定位置参数
overlay=x:y
  x=0, y=0              # 左上角
  x=W-w, y=H-h          # 右下角（W=主画面宽，w=水印宽）
  x=W-w-10, y=H-h-10    # 右下角（10px 边距）
  x=(W-w)/2, y=(H-h)/2  # 居中
```

**concat（拼接）**：多个视频时间轴拼接
```bash
# 时间轴拼接：video1 → video2 → video3
ffmpeg -i video1.mp4 -i video2.mp4 -i video3.mp4 \
  -filter_complex "
    [0:v][0:a][1:v][1:a][2:v][2:a] concat=n=3:v=1:a=1 [outv][outa]
  " \
  -map "[outv]" -map "[outa]" output.mp4

# 参数说明
concat=n=3:v=1:a=1
  n=3   # 输入段数（3个文件）
  v=1   # 每段有1条视频流
  a=1   # 每段有1条音频流
```

**hstack/vstack（网格拼接）**：空间并列
```bash
# 左右拼接（水平）
ffmpeg -i left.mp4 -i right.mp4 \
  -filter_complex "[0:v][1:v]hstack" \
  output.mp4

# 上下拼接（垂直）
ffmpeg -i top.mp4 -i bottom.mp4 \
  -filter_complex "[0:v][1:v]vstack" \
  output.mp4

# 2×2 网格（xstack）
ffmpeg -i v1.mp4 -i v2.mp4 -i v3.mp4 -i v4.mp4 \
  -filter_complex "
    [0:v][1:v][2:v][3:v] xstack=inputs=4:layout=0_0|w0_0|0_h0|w0_h0 [out]
  " \
  -map "[out]" grid.mp4
```

---

### 6.3 复杂分支合并示例

**画中画 + 双音轨**：
```bash
ffmpeg -i main.mp4 -i small.mp4 \
  -filter_complex "
    # 视频：小窗叠加在主画面右下角
    [0:v][1:v] overlay=W-w-20:H-h-20 [vout];
    
    # 音频：两路音频混合
    [0:a][1:a] amix=inputs=2:duration=first [aout]
  " \
  -map "[vout]" -map "[aout]" \
  -c:v libx264 -c:a aac output.mp4
```

**三分支处理**：
```bash
ffmpeg -i input.mp4 \
  -filter_complex "
    [0:v] split=3 [a][b][c];
    [a] scale=1920:1080, drawtext=text='HD':x=10:y=10 [hd];
    [b] scale=1280:720,  drawtext=text='SD':x=10:y=10 [sd];
    [c] scale=640:360,   drawtext=text='Mobile':x=10:y=10 [mobile]
  " \
  -map "[hd]" -map 0:a hd.mp4 \
  -map "[sd]" -map 0:a sd.mp4 \
  -map "[mobile]" -map 0:a mobile.mp4
```

## 7. 常用视频滤镜速查

### 7.1 尺寸与裁剪

**scale（缩放）**：
```bash
# 固定尺寸
scale=1280:720

# 保持宽高比（-2 自动计算为偶数）
scale=-2:720    # 高度 720，宽度自动
scale=1280:-2   # 宽度 1280，高度自动

# 缩放算法（默认 bicubic）
scale=1920:1080:flags=lanczos   # 高质量（慢）
scale=1920:1080:flags=bilinear  # 快速（质量低）

# 相对缩放
scale=iw/2:ih/2   # 缩小到 50%（iw=输入宽度，ih=输入高度）
```

**crop（裁剪）**：
```bash
# 基础语法：crop=w:h:x:y
crop=1280:720:0:0       # 从左上角裁剪 1280×720
crop=1280:720:320:180   # 从 (320,180) 裁剪

# 去除黑边
crop=iw:ih-80:0:40      # 去掉顶部 40px，底部 40px

# 裁剪中心区域
crop=iw/2:ih/2:(iw-ow)/2:(ih-oh)/2   # ow=输出宽，oh=输出高
```

**pad（填充黑边）**：
```bash
# 添加黑边到 16:9
pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black

# 参数：width:height:x:y:color
pad=1920:1080:0:0:white   # 白色背景
```

---

### 7.2 旋转与翻转

**transpose（顺时针 90° 旋转）**：
```bash
transpose=0   # 逆时针 90° + 垂直翻转
transpose=1   # 顺时针 90°
transpose=2   # 逆时针 90°
transpose=3   # 顺时针 90° + 垂直翻转
```

**rotate（任意角度旋转）**：
```bash
rotate=PI/4           # 旋转 45°
rotate='PI*t'         # 随时间旋转（t=当前时间秒）
rotate=PI/6:ow='hypot(iw,ih)':oh=ow  # 自动调整输出尺寸
```

**hflip / vflip（翻转）**：
```bash
hflip   # 水平翻转（镜像）
vflip   # 垂直翻转
```

---

### 7.3 叠加与水印

**overlay（叠加）**：
```bash
# 基础叠加
[0:v][1:v]overlay=x:y

# 常用位置
overlay=10:10                  # 左上角
overlay=W-w-10:10              # 右上角
overlay=10:H-h-10              # 左下角
overlay=W-w-10:H-h-10          # 右下角
overlay=(W-w)/2:(H-h)/2        # 居中

# 时间控制
overlay=10:10:enable='between(t,5,10)'  # 5-10 秒显示
```

### 7.4 文字与字幕

**drawtext（动态文字）**：
```bash
# 基础文字
drawtext=text='Hello World':x=10:y=10:fontsize=24:fontcolor=white

# 时间戳
drawtext=text='%{pts\:hms}':x=10:y=10:fontsize=20:fontcolor=white:box=1:boxcolor=black@0.5

# 滚动字幕
drawtext=text='Breaking News':x='w-mod(t*100,w+tw)':y=h-40:fontsize=28

# 淡入淡出
drawtext=text='Title':x=10:y=10:alpha='if(lt(t,2), t/2, if(lt(t,8), 1, (10-t)/2))'
```

**subtitles（嵌入字幕文件）**：
```bash
# 嵌入 SRT/ASS 字幕
subtitles=subtitle.srt
subtitles=subtitle.ass:force_style='FontSize=24,PrimaryColour=&H00FFFF'

# Windows 路径转义
subtitles=C\\:/path/to/subtitle.srt
```

### 7.5 色彩调整

**eq（亮度/对比度）**：
```bash
eq=brightness=0.1:contrast=1.2:saturation=1.5

# 参数范围
brightness: -1.0 到 1.0
contrast:   -2.0 到 2.0
saturation: 0.0 到 3.0
```

**hue（色调/饱和度）**：
```bash
hue=s=0        # 黑白（饱和度 0）
hue=h=60       # 色调偏移 60°
hue=s=1.5      # 饱和度提升 50%
```

**colorchannelmixer（通道混合器）**：
```bash
# 黑白高质量
colorchannelmixer=.3:.4:.3:0:.3:.4:.3:0:.3:.4:.3

# 暖色调
colorchannelmixer=rr=1.2:rb=0.8:br=0.8:bb=1.2
```

---

### 7.6 淡入淡出

**fade（淡入/淡出）**：
```bash
# 淡入（前 30 帧）
fade=in:0:30

# 淡出（从第 900 帧开始，持续 30 帧）
fade=out:900:30

# 淡入 + 淡出
fade=in:0:30,fade=out:900:30

# 指定颜色（淡入黑色）
fade=in:0:30:color=black
```

### 7.7 帧率与速度

**fps（改变帧率）**：
```bash
fps=30      # 固定 30fps
fps=fps=24  # 转换为 24fps（电影帧率）
```

**setpts（调整时间戳，实现变速）**：
```bash
# 2 倍速播放（音频也需调整）
```

### 8.1 音量控制

## 10. Go 滤镜系统封装

### 10.1 滤镜构建器设计

```go
package ffmpeg

import (
	"fmt"
	"strings"
)

// FilterChain 滤镜链构建器（简单 -vf 场景）
type FilterChain struct {
	filters []string
}

// NewFilterChain 创建新滤镜链
func NewFilterChain() *FilterChain {
	return &FilterChain{filters: make([]string, 0)}
}

// Scale 添加缩放滤镜
func (fc *FilterChain) Scale(width, height int) *FilterChain {
	fc.filters = append(fc.filters, fmt.Sprintf("scale=%d:%d", width, height))
	return fc
}

// ScaleWithAR 保持宽高比缩放（-2 = 自动计算为偶数）
func (fc *FilterChain) ScaleWithAR(width int) *FilterChain {
	fc.filters = append(fc.filters, fmt.Sprintf("scale=%d:-2", width))
	return fc
}

// Crop 裁剪
func (fc *FilterChain) Crop(w, h, x, y int) *FilterChain {
	fc.filters = append(fc.filters, fmt.Sprintf("crop=%d:%d:%d:%d", w, h, x, y))
	return fc
}

// FPS 设置帧率
func (fc *FilterChain) FPS(fps int) *FilterChain {
	fc.filters = append(fc.filters, fmt.Sprintf("fps=%d", fps))
	return fc
}

// Brightness 亮度调整
func (fc *FilterChain) Brightness(b float64) *FilterChain {
	fc.filters = append(fc.filters, fmt.Sprintf("eq=brightness=%.2f", b))
	return fc
}

// DrawText 添加文字
func (fc *FilterChain) DrawText(text, x, y string, fontSize int, color string) *FilterChain {
	f := fmt.Sprintf("drawtext=text='%s':x=%s:y=%s:fontsize=%d:fontcolor=%s",
		text, x, y, fontSize, color)
	fc.filters = append(fc.filters, f)
	return fc
}

// Build 构建滤镜链字符串
func (fc *FilterChain) Build() string {
	return strings.Join(fc.filters, ",")
}
```

### 10.2 复杂滤镜图构建器

```go
// FilterGraph 复杂滤镜图构建器（-filter_complex 场景）
type FilterGraph struct {
	nodes []string
	maps  []string
}

// NewFilterGraph 创建滤镜图构建器
func NewFilterGraph() *FilterGraph {
	return &FilterGraph{
		nodes: make([]string, 0),
		maps:  make([]string, 0),
	}
}

// AddNode 添加一条滤镜路径
// input: 输入标签（如 "[0:v]"）
// filter: 滤镜表达式（如 "scale=1280:720"）
// output: 输出标签（如 "[scaled]"）
func (fg *FilterGraph) AddNode(input, filter, output string) *FilterGraph {
	fg.nodes = append(fg.nodes, fmt.Sprintf("%s%s%s", input, filter, output))
	return fg
}

// AddMapOutput 添加 -map 输出
func (fg *FilterGraph) AddMapOutput(label string) *FilterGraph {
	fg.maps = append(fg.maps, fmt.Sprintf("-map '%s'", label))
	return fg
}

// BuildFilterComplex 构建 filter_complex 字符串
func (fg *FilterGraph) BuildFilterComplex() string {
	return strings.Join(fg.nodes, "; ")
}

// WatermarkOptions 水印配置
type WatermarkOptions struct {
	WatermarkPath string  // 水印图片路径
	Position      string  // topleft/topright/bottomleft/bottomright/center
	Margin        int     // 边距（像素）
	StartTime     float64 // 开始显示时间（秒，0 表示全程）
	EndTime       float64 // 结束显示时间（秒，0 表示全程）
}

// BuildWatermarkFilter 构建水印滤镜图
func BuildWatermarkFilter(opts WatermarkOptions) (filterComplex, mapFlag string) {
	// 确定位置
	var x, y string
	switch opts.Position {
	case "topleft":
		x = fmt.Sprintf("%d", opts.Margin)
		y = fmt.Sprintf("%d", opts.Margin)
	case "topright":
		x = fmt.Sprintf("W-w-%d", opts.Margin)
		y = fmt.Sprintf("%d", opts.Margin)
	case "bottomleft":
		x = fmt.Sprintf("%d", opts.Margin)
		y = fmt.Sprintf("H-h-%d", opts.Margin)
	case "bottomright":
		x = fmt.Sprintf("W-w-%d", opts.Margin)
		y = fmt.Sprintf("H-h-%d", opts.Margin)
	default: // center
		x = "(W-w)/2"
		y = "(H-h)/2"
	}
	
	// 时间控制
	enableExpr := ""
	if opts.StartTime > 0 || opts.EndTime > 0 {
		if opts.EndTime > 0 {
			enableExpr = fmt.Sprintf(":enable='between(t,%.1f,%.1f)'", opts.StartTime, opts.EndTime)
		} else {
			enableExpr = fmt.Sprintf(":enable='gte(t,%.1f)'", opts.StartTime)
		}
	}
	
	filterComplex = fmt.Sprintf("[0:v][1:v]overlay=%s:%s%s[out]", x, y, enableExpr)
	mapFlag = "[out]"
	return
}

// BuildSplitFilter 构建多分辨率分支滤镜图
func BuildSplitFilter(resolutions []Resolution) (filterComplex string, mapFlags []string) {
	n := len(resolutions)
	
	// split
	splitLabels := make([]string, n)
	for i := range resolutions {
		splitLabels[i] = fmt.Sprintf("[s%d]", i)
	}
	parts := []string{fmt.Sprintf("[0:v]split=%d%s", n, strings.Join(splitLabels, ""))}
	
	// 每路缩放
	mapFlags = make([]string, n)
	for i, res := range resolutions {
		outLabel := fmt.Sprintf("[out%d]", i)
		parts = append(parts, fmt.Sprintf("[s%d]scale=%d:%d%s", i, res.Width, res.Height, outLabel))
		mapFlags[i] = outLabel
	}
	
	filterComplex = strings.Join(parts, "; ")
	return
}

// Resolution 分辨率定义
type Resolution struct {
	Width  int
	Height int
	Label  string // e.g. "1080p"
}
```

### 10.3 使用示例

```go
package main

import (
	"fmt"
	"log"
	"os/exec"
)

func main() {
	// 场景 1：简单滤镜链（缩放 + 添加时间戳）
	chain := ffmpeg.NewFilterChain().
		Scale(1280, 720).
		DrawText("%{pts\\:hms}", "10", "10", 20, "white").
		Build()
	
	cmd := exec.Command("ffmpeg",
		"-i", "input.mp4",
		"-vf", chain,
		"-c:v", "libx264",
		"-c:a", "copy",
		"output.mp4",
	)
	
	fmt.Printf("滤镜链: %s\n", chain)
	// 输出: scale=1280:720,drawtext=text='%{pts\:hms}':x=10:y=10:fontsize=20:fontcolor=white
	
	if err := cmd.Run(); err != nil {
		log.Fatal(err)
	}
	
	// 场景 2：水印叠加
	opts := ffmpeg.WatermarkOptions{
		WatermarkPath: "logo.png",
		Position:      "bottomright",
		Margin:        20,
		StartTime:     5.0,  // 5 秒后显示
		EndTime:       60.0, // 60 秒后隐藏
	}
	
	filterComplex, mapFlag := ffmpeg.BuildWatermarkFilter(opts)
	
	cmd = exec.Command("ffmpeg",
		"-i", "video.mp4",
		"-i", opts.WatermarkPath,
		"-filter_complex", filterComplex,
		"-map", mapFlag,
		"-map", "0:a",
		"-c:v", "libx264",
		"-c:a", "copy",
		"watermarked.mp4",
	)
	
	fmt.Printf("水印滤镜: %s\n", filterComplex)
	// 输出: [0:v][1:v]overlay=W-w-20:H-h-20:enable='between(t,5.0,60.0)'[out]
	
	if err := cmd.Run(); err != nil {
		log.Fatal(err)
	}
	
	// 场景 3：多分辨率分支编码
	resolutions := []ffmpeg.Resolution{
		{Width: 1920, Height: 1080, Label: "1080p"},
		{Width: 1280, Height: 720, Label: "720p"},
		{Width: 854, Height: 480, Label: "480p"},
	}
	
	filterComplex, mapFlags := ffmpeg.BuildSplitFilter(resolutions)
	
	args := []string{"-i", "source.mp4", "-filter_complex", filterComplex}
	
	for i, res := range resolutions {
		args = append(args,
			"-map", mapFlags[i],
			"-map", "0:a",
			"-c:v", "libx264",
			"-c:a", "aac",
			fmt.Sprintf("output_%s.mp4", res.Label),
		)
	}
	
	cmd = exec.Command("ffmpeg", args...)
	
	fmt.Printf("分支滤镜: %s\n", filterComplex)
	// 输出: [0:v]split=3[s0][s1][s2]; [s0]scale=1920:1080[out0]; [s1]scale=1280:720[out1]; [s2]scale=854:480[out2]
	
	if err := cmd.Run(); err != nil {
		log.Fatal(err)
	}
}
```

## 12. 本篇小结

本篇系统讲解了 FFmpeg 滤镜系统的架构与基础用法：

**核心架构**：
- libavfilter 采用图结构（Filter Graph）组织滤镜
- 滤镜处理原始帧数据（YUV 像素 / PCM 样本），位于解码和编码之间
- 三层结构：AVFilterGraph（图）→ AVFilterContext（实例）→ AVFilterLink（连接）

**三种命令形式**：
- `-vf`：简单视频滤镜链（单输入单输出）
- `-af`：简单音频滤镜链（单输入单输出）
- `-filter_complex`：复杂滤镜图（多输入多输出、分支合并）

**语法规则**：
- 逗号（,）：滤镜链式连接，顺序执行
- 分号（;）：滤镜图路径分隔，支持并行处理
- 标签 `[...]`：命名输入/输出端口，连接滤镜节点
- `-map` 指令：显式指定哪个滤镜输出进入编码器

**常用滤镜**：
- 视频：scale, crop, overlay, drawtext, fade, fps, eq, hue
- 音频：volume, loudnorm, atempo, amix, afade, adelay

**工程化封装**：
- Go FilterChain：简单滤镜链构建器
- Go FilterGraph：复杂滤镜图构建器
- 水印、多分辨率分支等常见模式封装
