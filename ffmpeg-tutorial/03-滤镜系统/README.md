# 模块 3：滤镜系统

> 掌握 FFmpeg 强大的滤镜系统，实现缩放、水印、拼接等复杂视频处理需求。

## 本模块目标

- 理解滤镜图（Filter Graph）的语法和工作原理
- 掌握常用视频滤镜：缩放、裁剪、旋转、水印、字幕、色彩分级
- 掌握常用音频滤镜：音量归一化、混音、变速、降噪
- 学会多路合成、画面拼接、视频过渡效果
