## 1. 缩放与分辨率转换

### 1.1 缩放算法对比

```bash
# 最近邻（像素化，最快）
scale=1280:720:flags=neighbor

# 双线性（默认快速模式）
scale=1280:720:flags=bilinear

# 双立方（平衡速度与质量）
scale=1280:720:flags=bicubic

# Lanczos（最高质量，最慢）
scale=1280:720:flags=lanczos

# Sinc（高质量，适合大幅缩小）
scale=1280:720:flags=sinc
```

**速度 vs 质量权衡**：
```
neighbor   ← 最快       动画/像素艺术
bilinear   ← 快速       实时转码、直播
bicubic    ← 平衡       大多数场景默认选择
lanczos    ← 慢         离线转码、高质量输出
sinc       ← 最慢       专业制作
```

---

### 1.2 保持宽高比缩放

```bash
# 保持宽高比 — 限制高度
scale=-2:720     # 宽度自动计算（保证为偶数）
scale=-1:720     # 宽度自动计算（不保证为偶数，H.264 会报错）

# 保持宽高比 — 限制宽度
scale=1280:-2    # 高度自动计算（保证为偶数）

# 同时限制宽高（fit to box）
scale='min(1280,iw)':'min(720,ih)':force_original_aspect_ratio=decrease

# 放大到 1080p 并填充黑边
scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2:black
```

**理解 -2 vs -1**：
```
-1：让 FFmpeg 自动计算（保持比例），结果可能是奇数
-2：让 FFmpeg 自动计算，并强制结果为偶数
    H.264/H.265 要求宽高为偶数，所以应始终用 -2
```

---

### 1.3 多阶段缩放

```bash
# 大幅缩小（4K → 360p）分两步质量更好
scale=1920:1080:flags=lanczos,scale=640:360:flags=lanczos

# 相比一步直接缩小，两步方案锯齿更少
# 原理：Lanczos 在放大系数 < 0.5 时信息损失更均匀
```

## 2. 裁剪与画面构图

### 2.1 crop 基础语法

```bash
# crop=width:height:x:y
crop=1280:720:0:0        # 从左上角裁剪 1280×720
crop=1280:720:320:180    # 从 (320,180) 裁剪 1280×720

# 使用变量
crop=iw/2:ih/2:0:0       # 裁剪左上四分之一
crop=iw/2:ih/2:iw/2:ih/2 # 裁剪右下四分之一
```

---

### 2.2 自动去除黑边

```bash
# 去除顶部 40px，底部 40px 黑边
crop=iw:ih-80:0:40

# 去除左右各 100px 黑边
crop=iw-200:ih:100:0

# 去除四周黑边（各 10px）
crop=iw-20:ih-20:10:10
```

**检测黑边脚本**：
```bash
#!/bin/bash
# detect_black_bars.sh - 自动检测视频黑边

INPUT=$1

# cropdetect 滤镜：自动检测裁剪区域
ffmpeg -i "$INPUT" -vf cropdetect=24:16:0 -f null - 2>&1 | \
  grep "crop=" | tail -1 | sed 's/.*crop=//'

# 输出示例：1920:800:0:140
# 解释：宽1920，高800，从 (0, 140) 开始裁剪
```

**应用自动检测结果**：
```bash
CROP_PARAMS=$(bash detect_black_bars.sh input.mp4)
ffmpeg -i input.mp4 -vf "crop=$CROP_PARAMS" output.mp4
```

## 3. 旋转与翻转

### 3.1 transpose（90° 旋转）

```bash
# 顺时针 90°
transpose=1
# 等价于
transpose=clock

# 逆时针 90°
transpose=2
# 等价于
transpose=cclock

# 顺时针 90° + 垂直翻转
transpose=3

# 逆时针 90° + 垂直翻转
transpose=0
```

**旋转 180°**：
```bash
# 方法1：两次 90° 旋转
transpose=1,transpose=1

# 方法2：使用 hflip + vflip（更快）
hflip,vflip
```

---

### 3.2 rotate（任意角度旋转）

```bash
# 旋转 45°
rotate=PI/4

# 旋转 30° 并自动调整输出尺寸
rotate=PI/6:ow='hypot(iw,ih)':oh=ow:fillcolor=black

# 随时间旋转（每秒 90°）
rotate='PI/2*t'

# 参数说明
rotate=angle:ow:oh:fillcolor
  angle      旋转角度（弧度）
  ow/oh      输出宽高（默认等于输入，会裁剪超出部分）
  fillcolor  填充颜色（默认黑色）
```

**度数 → 弧度转换**：
```
30°  = PI/6
45°  = PI/4
60°  = PI/3
90°  = PI/2
180° = PI
```

---

### 3.3 翻转

```bash
# 水平翻转（镜像）
hflip

# 垂直翻转
vflip

# 同时水平和垂直翻转（等于旋转 180°）
hflip,vflip
```

## 4. 水印高级用法

### 4.1 基础水印叠加

```bash
# 左上角水印
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=10:10" \
  output.mp4

# 右下角水印（10px 边距）
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=W-w-10:H-h-10" \
  output.mp4

# 居中水印
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=(W-w)/2:(H-h)/2" \
  output.mp4
```

**位置速查**：
```
左上角：x=10:y=10
右上角：x=W-w-10:y=10
左下角：x=10:y=H-h-10
右下角：x=W-w-10:H-h-10
居中：x=(W-w)/2:y=(H-h)/2
左中：x=10:y=(H-h)/2
右中：x=W-w-10:y=(H-h)/2
```

---

### 4.2 透明度控制

```bash
# 半透明水印（50% 透明度）
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[1:v]colorchannelmixer=aa=0.5[logo]; [0:v][logo]overlay=W-w-10:H-h-10" \
  output.mp4

# 动态透明度（淡入淡出）
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "
    [1:v]format=rgba,colorchannelmixer=aa='if(lt(t,2),t/2,if(lt(t,58),1,(60-t)/2))'[logo];
    [0:v][logo]overlay=W-w-10:H-h-10
  " output.mp4
```

---

### 4.3 时间控制水印

```bash
# 前 10 秒显示水印
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=W-w-10:H-h-10:enable='between(t,0,10)'" \
  output.mp4

# 5 秒后才显示（之后一直显示）
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=W-w-10:H-h-10:enable='gte(t,5)'" \
  output.mp4

# 间歇显示（每 10 秒显示 5 秒）
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=W-w-10:H-h-10:enable='lt(mod(t,10),5)'" \
  output.mp4
```

---

### 4.4 动态水印位置

```bash
# 从左到右移动
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=x='t*100':y=10" \
  output.mp4

# 弹跳效果
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "[0:v][1:v]overlay=x=W-w-10:y='abs(sin(t*2))*100+10'" \
  output.mp4

# 圆形轨迹
ffmpeg -i video.mp4 -i logo.png \
  -filter_complex "
    [0:v][1:v]overlay=x='W/2-w/2+cos(t)*200':y='H/2-h/2+sin(t)*200'
  " output.mp4
```

---

### 4.5 批量水印（多个水印）

```bash
# 四角同时显示不同水印
ffmpeg -i video.mp4 -i logo1.png -i logo2.png -i logo3.png -i logo4.png \
  -filter_complex "
    [0:v][1:v]overlay=10:10[v1];
    [v1][2:v]overlay=W-w-10:10[v2];
    [v2][3:v]overlay=10:H-h-10[v3];
    [v3][4:v]overlay=W-w-10:H-h-10[out]
  " \
  -map "[out]" output.mp4
```

## 6. 淡入淡出与过渡效果

### 6.1 fade 滤镜

```bash
# 淡入（前 30 帧，约 1 秒@30fps）
fade=in:0:30

# 淡出（从第 870 帧开始，持续 30 帧）
# 如果视频共 900 帧，最后 1 秒淡出
fade=out:870:30

# 淡入 + 淡出（一条命令）
fade=in:0:30,fade=out:870:30

# 指定颜色（淡入白色）
fade=in:0:30:color=white
```

---

### 6.2 计算淡出起始帧

```bash
#!/bin/bash
# 计算淡出开始帧（最后 N 秒）

INPUT=$1
FADEIN_DURATION=1   # 淡入秒数
FADEOUT_DURATION=1  # 淡出秒数

# 获取视频总帧数
TOTAL_FRAMES=$(ffprobe -v error -select_streams v:0 \
  -show_entries stream=nb_frames -of csv=p=0 "$INPUT")

# 获取帧率
FPS=$(ffprobe -v error -select_streams v:0 \
  -show_entries stream=avg_frame_rate -of csv=p=0 "$INPUT" | bc)

FADEIN_FRAMES=$(echo "$FADEIN_DURATION * $FPS" | bc | cut -d. -f1)
FADEOUT_FRAMES=$(echo "$FADEOUT_DURATION * $FPS" | bc | cut -d. -f1)
FADEOUT_START=$((TOTAL_FRAMES - FADEOUT_FRAMES))

echo "fade=in:0:$FADEIN_FRAMES,fade=out:$FADEOUT_START:$FADEOUT_FRAMES"
```

---

### 6.3 交叉溶解（Cross Dissolve）

FFmpeg 没有内置交叉溶解滤镜，可用以下方法模拟：

```bash
# 方法：第一段淡出 + 第二段淡入 + 混合
ffmpeg -i video1.mp4 -i video2.mp4 \
  -filter_complex "
    # 视频1：最后1秒淡出
    [0:v]fade=out:$(ffprobe -v error -select_streams v:0 -show_entries stream=nb_frames -of csv=p=0 video1.mp4 | xargs -I{} echo "{} - 30" | bc):30[v1_fade];
    
    # 视频2：前1秒淡入，使用 alpha
    [1:v]fade=in:0:30[v2_fade];
    
    # 拼接（简化：不是真正的叠化，是顺序拼接）
    [v1_fade][v2_fade]concat=n=2:v=1[out]
  " \
  -map "[out]" output.mp4
```

## 7. 色彩分级与校正

### 7.1 基础色彩调整（eq 滤镜）

```bash
# 亮度/对比度/饱和度/伽马
eq=brightness=0.05:contrast=1.3:saturation=1.2:gamma=1.0

# 参数范围
# brightness: -1.0 到 1.0（0 = 不变）
# contrast:   -2.0 到 2.0（1 = 不变）
# saturation: 0.0 到 3.0（1 = 不变）
# gamma:       0.1 到 10.0（1 = 不变）

# 高对比度黑白
eq=saturation=0:contrast=1.5

# 复古低饱和风格
eq=brightness=-0.05:contrast=0.9:saturation=0.6
```

---

### 7.2 颜色通道混合器

```bash
# 高质量黑白（加权平均）
colorchannelmixer=rr=0.299:rg=0.587:rb=0.114:gr=0.299:gg=0.587:gb=0.114:br=0.299:bg=0.587:bb=0.114

# 暖色调（增强红色，减少蓝色）
colorchannelmixer=rr=1.1:gb=0.9:bb=0.9

# 冷色调（增强蓝色，减少红色）
colorchannelmixer=rr=0.9:gb=1.0:bb=1.1

# 负片效果

```

### 7.4 LUT（查找表）色彩分级

LUT（Look-Up Table）是电影级色彩校正工具，将一组颜色映射到另一组颜色。

```bash
# 应用 3D LUT（.cube 格式）
```

## 8. 去隔行与视频稳定

### 8.1 yadif（去隔行滤镜）

**什么是隔行视频**：老式 TV 信号/DVD 使用隔行扫描（每帧只扫描奇数行或偶数行），在现代显示器上会出现水平条纹。

```bash
# yadif 基础（每帧输出一帧，每秒帧数不变）
yadif

# yadif=mode（每帧输出两帧，帧率翻倍）
yadif=1   # 插帧去隔行，1080i60 → 1080p60

# 参数
yadif=mode:parity:deint
  mode=0   每帧输出一帧（默认）
  mode=1   每场输出一帧（帧率翻倍）
  mode=2   仅处理有问题的帧
  parity=-1  自动检测（默认）
```

**判断视频是否隔行**：
```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=field_order -of csv=p=0 input.mp4
# 输出：tb/tt/bb/bt = 隔行；progressive = 逐行
```

---

### 8.2 vidstab（视频防抖）

视频稳定需要两遍处理：

```bash
# 第一遍：分析运动（生成 transforms.trf 文件）
ffmpeg -i shaky.mp4 \
  -vf vidstabdetect=stepsize=6:shakiness=8:accuracy=9:result=transforms.trf \
  -f null -

# 第二遍：应用稳定变换
ffmpeg -i shaky.mp4 \
  -vf vidstabtransform=input=transforms.trf:zoom=5:smoothing=30 \
  stabilized.mp4

# 参数说明
# vidstabdetect
  shakiness=8    震动强度（1-10，越大越激进）
  accuracy=9     检测精度（1-15，越大越准确）
  stepsize=6     检测步长（越小越精细）

# vidstabtransform
  zoom=5         裁剪边缘（%），避免黑边（稳定后边缘会抖）
  smoothing=30   平滑帧数（越大越平滑，15fps 下约 2 秒）
  interpol=bilinear  插值算法
```

**完整稳定脚本**：
```bash
#!/bin/bash
INPUT=$1
OUTPUT="${INPUT%.*}_stabilized.${INPUT##*.}"
TRANSFORMS="/tmp/vidstab_transforms.trf"

echo "步骤 1：分析运动..."
ffmpeg -i "$INPUT" \
  -vf "vidstabdetect=shakiness=8:accuracy=9:result=$TRANSFORMS" \
  -f null - 2>&1 | grep -E "frame|pts"

echo "步骤 2：应用稳定..."
ffmpeg -i "$INPUT" \
  -vf "vidstabtransform=input=$TRANSFORMS:zoom=5:smoothing=30,unsharp=5:5:0.8:3:3:0.4" \
  -c:v libx264 -crf 18 -c:a copy \
  "$OUTPUT"

echo "完成：$OUTPUT"
rm -f "$TRANSFORMS"
```

## 10. Go 工程化封装

### 10.1 高级滤镜构建器

```go
package ffmpeg

import (
	"fmt"
	"strings"
)

// AdvancedFilterBuilder 高级滤镜构建器
type AdvancedFilterBuilder struct {
	chain *FilterChain
}

// NewAdvancedFilterBuilder 创建高级滤镜构建器
func NewAdvancedFilterBuilder() *AdvancedFilterBuilder {
	return &AdvancedFilterBuilder{
		chain: NewFilterChain(),
	}
}

// Watermark 添加水印
type WatermarkConfig struct {
	ImagePath   string
	Position    string  // topleft/topright/bottomleft/bottomright/center
	Margin      int
	Opacity     float64 // 0.0-1.0
	StartTime   float64 // 秒
	EndTime     float64 // 秒，0 表示全程
}

// BuildWatermarkCommand 构建完整水印命令
func BuildWatermarkCommand(videoPath string, cfg WatermarkConfig) []string {
	var x, y string
	margin := cfg.Margin
	
	switch cfg.Position {
	case "topleft":
		x, y = fmt.Sprintf("%d", margin), fmt.Sprintf("%d", margin)
	case "topright":
		x, y = fmt.Sprintf("W-w-%d", margin), fmt.Sprintf("%d", margin)
	case "bottomleft":
		x, y = fmt.Sprintf("%d", margin), fmt.Sprintf("H-h-%d", margin)
	case "bottomright":
		x, y = fmt.Sprintf("W-w-%d", margin), fmt.Sprintf("H-h-%d", margin)
	default: // center
		x, y = "(W-w)/2", "(H-h)/2"
	}
	
	// 构建滤镜
	var filters []string
	
	// 透明度
	if cfg.Opacity < 1.0 {
		filters = append(filters, fmt.Sprintf("[1:v]format=rgba,colorchannelmixer=aa=%.2f[logo]", cfg.Opacity))
	} else {
		filters = append(filters, "[1:v]null[logo]")
	}
	
	// 叠加
	overlayFilter := fmt.Sprintf("[0:v][logo]overlay=%s:%s", x, y)
	
	// 时间控制
	if cfg.StartTime > 0 || cfg.EndTime > 0 {
		if cfg.EndTime > 0 {
			overlayFilter += fmt.Sprintf(":enable='between(t,%.1f,%.1f)'", cfg.StartTime, cfg.EndTime)
		} else {
			overlayFilter += fmt.Sprintf(":enable='gte(t,%.1f)'", cfg.StartTime)
		}
	}
	
	filters = append(filters, overlayFilter+"[out]")
	
	return []string{
		"-i", videoPath,
		"-i", cfg.ImagePath,
		"-filter_complex", strings.Join(filters, "; "),
		"-map", "[out]",
		"-map", "0:a",
	}
}

// ColorGradePreset 色彩预设
type ColorGradePreset string

const (
	ColorGradeNone       ColorGradePreset = "none"
	ColorGradeWarm       ColorGradePreset = "warm"
	ColorGradeCool       ColorGradePreset = "cool"
	ColorGradeVintage    ColorGradePreset = "vintage"
	ColorGradeHighContrast ColorGradePreset = "high_contrast"
	ColorGradeBlackWhite ColorGradePreset = "black_white"
)

// BuildColorGradeFilter 构建色彩分级滤镜
func BuildColorGradeFilter(preset ColorGradePreset) string {
	switch preset {
	case ColorGradeWarm:
		return "colorchannelmixer=rr=1.1:gb=0.9:bb=0.9"
	case ColorGradeCool:
		return "colorchannelmixer=rr=0.9:gb=1.0:bb=1.1"
	case ColorGradeVintage:
		return "eq=brightness=-0.05:contrast=0.9:saturation=0.6,colorchannelmixer=rr=1.05:gg=0.95:bb=0.9"
	case ColorGradeHighContrast:
		return "eq=contrast=1.5:saturation=1.2"
	case ColorGradeBlackWhite:
		return "colorchannelmixer=rr=0.299:rg=0.587:rb=0.114:gr=0.299:gg=0.587:gb=0.114:br=0.299:bg=0.587:bb=0.114"
	default:
		return ""
	}
}

// TimestampConfig 时间戳配置
type TimestampConfig struct {
	Position  string  // topleft/topright/bottomleft/bottomright
	FontSize  int
	FontColor string
	BoxColor  string  // 背景框颜色，如 "black@0.5"
}

// BuildTimestampFilter 构建时间戳滤镜
func BuildTimestampFilter(cfg TimestampConfig) string {
	var x, y string
	
	switch cfg.Position {
	case "topleft":
		x, y = "10", "10"
	case "topright":
		x, y = "w-text_w-10", "10"
	case "bottomleft":
		x, y = "10", "h-text_h-10"
	default: // bottomright
		x, y = "w-text_w-10", "h-text_h-10"
	}
	
	parts := []string{
		fmt.Sprintf("text='%%{pts\\:hms}'"),
		fmt.Sprintf("x=%s", x),
		fmt.Sprintf("y=%s", y),
		fmt.Sprintf("fontsize=%d", cfg.FontSize),
		fmt.Sprintf("fontcolor=%s", cfg.FontColor),
	}
	
	if cfg.BoxColor != "" {
		parts = append(parts, "box=1", fmt.Sprintf("boxcolor=%s", cfg.BoxColor))
	}
	
	return "drawtext=" + strings.Join(parts, ":")
}
```

### 10.2 使用示例

```go
package main

import (
	"fmt"
	"log"
	"os/exec"
)

func main() {
	// 场景 1：添加水印
	watermarkCfg := ffmpeg.WatermarkConfig{
		ImagePath: "logo.png",
		Position:  "bottomright",
		Margin:    20,
		Opacity:   0.7,
		StartTime: 5.0,
		EndTime:   60.0,
	}
	
	args := ffmpeg.BuildWatermarkCommand("input.mp4", watermarkCfg)
	args = append(args, "-c:v", "libx264", "-crf", "23", "-c:a", "copy", "output.mp4")
	
	cmd := exec.Command("ffmpeg", args...)
	if err := cmd.Run(); err != nil {
		log.Fatal(err)
	}
	
	// 场景 2：色彩分级
	colorFilter := ffmpeg.BuildColorGradeFilter(ffmpeg.ColorGradeVintage)
	
	cmd = exec.Command("ffmpeg",
		"-i", "input.mp4",
		"-vf", colorFilter,
		"-c:v", "libx264", "-crf", "23",
		"-c:a", "copy",
		"vintage_output.mp4",
	)
	
	if err := cmd.Run(); err != nil {
		log.Fatal(err)
	}
	
	// 场景 3：添加时间戳
	timestampCfg := ffmpeg.TimestampConfig{
		Position:  "topright",
		FontSize:  20,
		FontColor: "white",
		BoxColor:  "black@0.5",
	}
	
	timestampFilter := ffmpeg.BuildTimestampFilter(timestampCfg)
	
	cmd = exec.Command("ffmpeg",
		"-i", "input.mp4",
		"-vf", timestampFilter,
		"-c:v", "libx264", "-crf", "23",
		"-c:a", "copy",
		"timestamped.mp4",
	)
	
	if err := cmd.Run(); err != nil {
		log.Fatal(err)
	}
	
	// 场景 4：组合滤镜（缩放 + 色彩 + 时间戳）
	chain := ffmpeg.NewFilterChain().
		Scale(1280, 720).
		Build()
	
	combinedFilter := chain + "," + colorFilter + "," + timestampFilter
	
	cmd = exec.Command("ffmpeg",
		"-i", "input.mp4",
		"-vf", combinedFilter,
		"-c:v", "libx264", "-crf", "23",
		"-c:a", "copy",
		"combined_output.mp4",
	)
	
	fmt.Printf("组合滤镜: %s\n", combinedFilter)
	
	if err := cmd.Run(); err != nil {
		log.Fatal(err)
	}
}
```

## 12. 本篇小结

本篇深入讲解了视频滤镜的实战用法：

**缩放与裁剪**：
- scale 算法对比：lanczos（高质量）vs bilinear（快速）
- 保持宽高比：`scale=-2:720`（-2 强制偶数）
- crop 自动去黑边：cropdetect 滤镜检测 + crop 应用

**水印系统**：
- 位置控制：topleft/topright/bottomleft/bottomright/center
- 透明度：colorchannelmixer=aa=0.5
- 时间控制：enable='between(t,5,60)'
- 动态效果：位置表达式实现运动轨迹

**字幕与文字**：
- drawtext：固定文字、时间码、滚动字幕
- subtitles：嵌入 SRT/ASS 字幕文件
- 淡入淡出：alpha 参数控制透明度

**色彩处理**：
- eq：亮度/对比度/饱和度/伽马
- colorchannelmixer：通道级色彩调整
- hue：色调偏移和饱和度控制
- lut3d：电影级色彩分级（LUT 文件）

**高级滤镜**：
- yadif：去隔行扫描（1080i → 1080p）
- vidstab：两遍视频防抖（detect + transform）
- fade：淡入淡出效果

**硬件加速**：
- CUDA：scale_cuda, overlay_cuda（NVIDIA）
- QSV：scale_qsv, overlay_qsv（Intel）
- VideoToolbox：scale_vt（macOS）

**工程化**：
- Go 封装水印、色彩预设、时间戳构建器
- 批量处理和滤镜组合策略
