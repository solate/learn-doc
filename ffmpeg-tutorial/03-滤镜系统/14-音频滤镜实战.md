## 1. 音频滤镜架构概览

### 1.1 libavfilter 音频处理管道

```
┌─────────────┐      ┌──────────────┐      ┌─────────────┐
│ 解封装      │──────▶│ 解码器       │──────▶│ 音频滤镜    │
│ Demuxer     │ 压缩流│ Audio Decoder│ PCM   │ Audio Filter│
└─────────────┘      └──────────────┘      └─────────────┘
                                                   │
                                                   ▼ PCM
                                            ┌─────────────┐
                                            │ 编码器      │
                                            │ Audio Encoder│
                                            └─────────────┘
```

**关键概念**：
- **采样格式**：s16/s32/flt/fltp（平面 vs 交织）
- **采样率**：8000/16000/44100/48000 Hz
- **声道布局**：mono/stereo/5.1/7.1

### 1.2 音频滤镜语法

```bash
# 单滤镜
ffmpeg -i input.mp3 -af "volume=2.0" output.mp3

# 滤镜链（逗号分隔，串行）
ffmpeg -i input.mp3 -af "volume=0.5,highpass=f=200" output.mp3

# 复杂滤镜图（用于多输入）
ffmpeg -i music.mp3 -i voice.mp3 \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=longest" output.mp3
```

## 2. 音量控制：volume 滤镜

### 2.1 基础用法

```bash
# 音量放大 2 倍（+6dB）
ffmpeg -i input.mp3 -af "volume=2.0" output.mp3

# 音量降低一半（-6dB）
ffmpeg -i input.mp3 -af "volume=0.5" output.mp3

# 使用 dB 单位（-10dB 衰减）
ffmpeg -i input.mp3 -af "volume=-10dB" output.mp3
```

### 2.2 动态音量调整

```bash
# 淡入效果（0秒开始，持续3秒，从0到1）
ffmpeg -i input.mp3 -af "volume=enable='between(t,0,3)':volume='t/3'" fade_in.mp3

# 淡出效果（假设时长10秒，最后3秒淡出）
ffmpeg -i input.mp3 -af "volume=enable='gte(t,7)':volume='1-(t-7)/3'" fade_out.mp3

# 区间静音（5-8秒静音）
ffmpeg -i input.mp3 -af "volume=enable='between(t,5,8)':volume=0" muted.mp3
```

### 2.3 精确控制

```bash
# 限制最大音量防止削波（软限幅）
ffmpeg -i input.mp3 -af "volume=2.0,alimiter=limit=0.9" safe.mp3

# 基于元数据标签动态调整
ffmpeg -i input.mp3 -af "volume=@replaygain_track_gain dB" normalized.mp3
```

## 3. 响度归一化：loudnorm 与 EBU R128

### 3.1 EBU R128 标准

**EBU R128** 是欧洲广播联盟制定的响度标准，用于统一不同节目的音量感知：

- **目标响度**：-23 LUFS（电视）/ -16 LUFS（流媒体）/ -14 LUFS（YouTube）
- **响度范围（LRA）**：7-20 LU（动态范围）
- **真峰值（True Peak）**：-1 dBTP（防止编码后削波）

### 3.2 单遍归一化（快速但不精确）

```bash
ffmpeg -i input.mp3 -af "loudnorm=I=-16:TP=-1.5:LRA=11" output.mp3
```

参数说明：
- `I=-16`：目标响度 -16 LUFS（流媒体标准）
- `TP=-1.5`：真峰值限制 -1.5 dBTP
- `LRA=11`：目标响度范围 11 LU

### 3.3 两遍归一化（精确）

**第一遍**：分析原始响度

```bash
ffmpeg -i input.mp3 -af "loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json" -f null -
```

输出示例：

```json
{
  "input_i" : "-18.70",
  "input_tp" : "-0.18",
  "input_lra" : "5.80",
  "input_thresh" : "-29.71",
  "target_offset" : "1.30"
}
```

**第二遍**：应用精确偏移

```bash
ffmpeg -i input.mp3 -af "loudnorm=I=-16:TP=-1.5:LRA=11:\
measured_I=-18.70:measured_LRA=5.80:measured_TP=-0.18:\
measured_thresh=-29.71:offset=1.30" output.mp3
```

## 4. 动态范围压缩：compand 滤镜

### 4.1 压缩原理

**动态范围压缩**减小音频最大值与最小值的差距：

```
原始信号：|====       |  （峰值高，谷值低）
压缩后：  |======     |  （峰值降低，谷值提升）
```

### 4.2 人声增强（降低背景音乐）

```bash
ffmpeg -i podcast.mp3 -af "compand=attacks=0.3:decays=0.8:points=-80/-80|-45/-15|-27/-9|0/-7" enhanced.mp3
```

参数解析：
- `attacks=0.3`：压缩启动时间 0.3 秒
- `decays=0.8`：压缩释放时间 0.8 秒
- `points`：传递函数（输入dB/输出dB）
  - `-80/-80`：-80dB 以下保持不变（噪声门）
  - `-45/-15`：-45dB 提升到 -15dB（提升低音量）
  - `0/-7`：0dB 压缩到 -7dB（限制峰值）

### 4.3 广播级压缩

```bash
# 标准 3:1 压缩比（-18dB 阈值）
ffmpeg -i input.mp3 -af "compand=attacks=0.1:decays=0.5:points=-80/-80|-18/-12|0/-6:soft-knee=6" broadcast.mp3
```

**soft-knee=6**：在阈值附近平滑过渡 6dB，避免突变。

## 5. 变速不变调：atempo 滤镜

### 5.1 基础用法

```bash
# 2倍速播放（时长减半）
ffmpeg -i input.mp3 -af "atempo=2.0" 2x.mp3

# 0.5倍速播放（时长翻倍）
ffmpeg -i input.mp3 -af "atempo=0.5" half_speed.mp3
```

**限制**：`atempo` 范围是 **0.5 ~ 2.0**。

### 5.2 突破限制：链式调用

```bash
# 4倍速（2.0 × 2.0）
ffmpeg -i input.mp3 -af "atempo=2.0,atempo=2.0" 4x.mp3

# 8倍速（2.0 × 2.0 × 2.0）
ffmpeg -i input.mp3 -af "atempo=2.0,atempo=2.0,atempo=2.0" 8x.mp3

# 0.25倍速（0.5 × 0.5）
ffmpeg -i input.mp3 -af "atempo=0.5,atempo=0.5" quarter_speed.mp3

# 1.5倍速（先2倍再0.75，因为 1.5 超出单次范围需拆分）
ffmpeg -i input.mp3 -af "atempo=2.0,atempo=0.75" 1.5x.mp3
```

### 5.3 视频同步变速

```bash
# 视频+音频同步2倍速
ffmpeg -i input.mp4 -filter_complex "[0:v]setpts=0.5*PTS[v];[0:a]atempo=2.0[a]" \
  -map "[v]" -map "[a]" 2x.mp4
```

**原理**：
- 视频：`setpts=0.5*PTS`（时间戳减半）
- 音频：`atempo=2.0`（速度翻倍）

## 6. 声道处理：pan 与 channelmap

### 6.1 立体声转单声道

```bash
# 方法1：简单混合（左右声道平均）
ffmpeg -i stereo.mp3 -ac 1 mono.mp3

# 方法2：使用 pan 滤镜（精确控制）
ffmpeg -i stereo.mp3 -af "pan=mono|c0=0.5*c0+0.5*c1" mono.mp3
```

### 6.2 提取特定声道

```bash
# 只保留左声道
ffmpeg -i stereo.mp3 -af "pan=mono|c0=c0" left_only.mp3

# 只保留右声道
ffmpeg -i stereo.mp3 -af "pan=mono|c0=c1" right_only.mp3

# 使用 channelmap（另一种方法）
ffmpeg -i stereo.mp3 -af "channelmap=0-0" left_only.mp3
```

### 6.3 立体声声道交换

```bash
# 左右声道互换
ffmpeg -i stereo.mp3 -af "pan=stereo|c0=c1|c1=c0" swapped.mp3

# 使用 channelmap
ffmpeg -i stereo.mp3 -af "channelmap=1|0" swapped.mp3
```

### 6.4 5.1 环绕声降混到立体声

```bash
# 标准降混公式（ITU-R BS.775）
ffmpeg -i 5.1.ac3 -af "pan=stereo|\
c0=FC+0.707*FL+0.707*BL|\
c1=FC+0.707*FR+0.707*BR" stereo.mp3
```

声道缩写：
- `FL/FR`：前左/前右
- `FC`：中置
- `BL/BR`：后左/后右
- `LFE`：低频效果（.1 声道）

## 7. 混音合并：amix 与 amerge

### 7.1 amix：多路音频混合

```bash
# 背景音乐 + 人声混合（等音量）
ffmpeg -i voice.mp3 -i bgm.mp3 \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=first:dropout_transition=3" \
  mixed.mp3
```

参数说明：
- `inputs=2`：输入流数量
- `duration=first`：以第一个输入时长为准（也可用 `longest`/`shortest`）
- `dropout_transition=3`：某路输入结束后 3 秒渐出

```bash
# 背景音乐降低音量混合（人声 100%，BGM 30%）
ffmpeg -i voice.mp3 -i bgm.mp3 \
  -filter_complex "[1:a]volume=0.3[bgm];[0:a][bgm]amix=inputs=2:duration=first" \
  mixed_with_bgm.mp3
```

### 7.2 amerge：声道合并

```bash
# 两个单声道合并成立体声
ffmpeg -i left.mp3 -i right.mp3 \
  -filter_complex "[0:a][1:a]amerge=inputs=2" \
  -ac 2 stereo.mp3

# 两个单声道合并成立体声（pan 控制）
ffmpeg -i left.mp3 -i right.mp3 \
  -filter_complex "[0:a][1:a]amerge=inputs=2[merged];[merged]pan=stereo|c0=c0|c1=c1" \
  -ac 2 stereo.mp3
```

## 8. 音频特效：回声、合唱、均衡器

### 8.1 回声效果（aecho）

```bash
# 简单回声（延迟600ms，40%反馈）
ffmpeg -i input.mp3 -af "aecho=0.8:0.88:60:0.4" echo.mp3
```

参数：`aecho=in_gain:out_gain:delays:decays`

```bash
# 多重回声（山谷效果）
ffmpeg -i input.mp3 -af "aecho=0.8:0.88:60|120|240:0.4|0.3|0.2" valley_echo.mp3

# 混响效果（短延迟多次）
ffmpeg -i input.mp3 -af "aecho=0.8:0.9:10|20|30:0.5|0.3|0.2" reverb.mp3
```

### 8.2 合唱效果（chorus）

```bash
# 基础合唱效果
ffmpeg -i input.mp3 -af "chorus=0.5:0.9:50|60|40:0.4|0.32|0.3:0.25|0.4|0.3:2|2.3|1.3" chorus.mp3
```

### 8.3 均衡器（equalizer/bass/treble）

```bash
# 高通滤波（去除 200Hz 以下低频噪声）
ffmpeg -i input.mp3 -af "highpass=f=200" cleaned.mp3

# 低通滤波（去除 8000Hz 以上高频噪声）
ffmpeg -i input.mp3 -af "lowpass=f=8000" muffled.mp3

# 参数均衡（对 1kHz 提升 3dB，Q=1.5）
ffmpeg -i input.mp3 -af "equalizer=f=1000:width_type=o:width=1.5:g=3" eq.mp3

# 增强低音（100Hz 提升 5dB）
ffmpeg -i input.mp3 -af "bass=g=5:f=100:width_type=o:width=2" bass_boost.mp3

# 增强高音（4kHz 提升 3dB）
ffmpeg -i input.mp3 -af "treble=g=3:f=4000" treble_boost.mp3

# 语音清晰度优化（组合滤镜链）
ffmpeg -i podcast.mp3 -af "highpass=f=100,lowpass=f=12000,equalizer=f=2500:width_type=o:width=2:g=2" voice.mp3
```

## 9. 音频分析：volumedetect 与 astats

### 9.1 volumedetect：音量统计

```bash
# 分析音量分布
ffmpeg -i input.mp3 -af "volumedetect" -f null -
```

输出示例：

```
[Parsed_volumedetect_0] mean_volume: -18.5 dB
[Parsed_volumedetect_0] max_volume: -0.2 dB
[Parsed_volumedetect_0] histogram_0db: 16
[Parsed_volumedetect_0] histogram_-1db: 132
[Parsed_volumedetect_0] histogram_-2db: 1024
```

- `mean_volume`：平均响度（近似 RMS）
- `max_volume`：最大峰值（用于判断是否削波）

### 9.2 astats：详细音频统计

```bash
# 全局统计（每声道）
ffmpeg -i input.mp3 -af "astats" -f null -

# 每 N 秒统计一次（用于分析动态变化）
ffmpeg -i input.mp3 -af "astats=length=1:metadata=1,ametadata=print:key=lavfi.astats.Overall.RMS_level" -f null -
```

输出字段：
- `RMS_level`：RMS 电平（dB）
- `Peak_level`：峰值电平（dB）
- `Crest_factor`：峰值因子（峰值/RMS）
- `Dynamic_range`：动态范围（dB）
- `Noise_floor`：噪声本底

### 9.3 silencedetect：静音检测

```bash
# 检测 -40dB 以下持续超过 1 秒的静音段
ffmpeg -i input.mp3 -af "silencedetect=noise=-40dB:d=1" -f null -
```

输出示例：

```
[silencedetect] silence_start: 5.23
[silencedetect] silence_end: 8.45 | silence_duration: 3.22
```

## 10. 降噪与静音检测

### 10.1 afftdn：频域降噪

```bash
# 自动降噪（分析前 500ms 作为噪声样本）
ffmpeg -i noisy.mp3 -af "afftdn=nr=20:nf=-40:tn=1" denoised.mp3
```

参数：
- `nr=20`：降噪强度（0-97，越大越激进）
- `nf=-40`：噪声本底阈值（dB）
- `tn=1`：开启音调降噪

```bash
# 两步降噪：先采集噪声样本，再处理
# 步骤1：提取前1秒作为噪声特征
ffmpeg -i noisy.mp3 -af "atrim=0:1,afftdn=nm=oavg,asetnsamples=44100" noise_profile.mp3

# 步骤2：应用噪声模板（使用 anlmdn 替代方案）
ffmpeg -i noisy.mp3 -af "anlmdn=s=7:p=0.002:r=0.002:m=15" denoised.mp3
```

### 10.2 静音去除与裁剪

```bash
# 去除开头静音（silenceremove）
ffmpeg -i input.mp3 -af "silenceremove=start_periods=1:start_duration=1:start_threshold=-60dB" no_leading_silence.mp3

# 去除首尾静音
ffmpeg -i input.mp3 -af "silenceremove=start_periods=1:start_threshold=-60dB:stop_periods=1:stop_threshold=-60dB" trimmed.mp3

# 去除所有内部静音（适合播客剪辑）
ffmpeg -i podcast.mp3 -af "silenceremove=stop_periods=-1:stop_duration=0.5:stop_threshold=-50dB" compact.mp3
```

## 11. Go 集成：音频处理服务

### 11.1 响度归一化服务

```go
package audio

import (
	"context"
	"encoding/json"
	"fmt"
	"os/exec"
	"strings"
)

// LoudnessStats EBU R128 响度统计
type LoudnessStats struct {
	InputI         float64 `json:"input_i"`          // 输入响度（LUFS）
	InputTP        float64 `json:"input_tp"`         // 输入真峰值（dBTP）
	InputLRA       float64 `json:"input_lra"`        // 响度范围（LU）
	InputThresh    float64 `json:"input_thresh"`     // 响度门限
	TargetOffset   float64 `json:"target_offset"`    // 目标偏移量
	NormalizationType string `json:"normalization_type"` // dynamic/linear
}

// LoudnormService 响度归一化服务
type LoudnormService struct {
	workDir    string
	targetLUFS float64 // 目标响度（-16 流媒体 / -23 广播 / -14 YouTube）
	targetTP   float64 // 真峰值限制
	targetLRA  float64 // 响度范围
}

// AnalyzeLoudness 第一遍分析
func (s *LoudnormService) AnalyzeLoudness(ctx context.Context, inputPath string) (*LoudnessStats, error) {
	filterArgs := fmt.Sprintf("loudnorm=I=%.1f:TP=%.1f:LRA=%.1f:print_format=json",
		s.targetLUFS, s.targetTP, s.targetLRA)
	
	cmd := exec.CommandContext(ctx, "ffmpeg",
		"-i", inputPath,
		"-af", filterArgs,
		"-f", "null", "-",
	)
	
	output, err := cmd.CombinedOutput()
	if err != nil && !strings.Contains(string(output), "input_i") {
		return nil, fmt.Errorf("分析失败: %w", err)
	}
	
	// 提取 JSON 部分（从最后一个 { 开始）
	jsonStart := strings.LastIndex(string(output), "{")
	if jsonStart == -1 {
		return nil, fmt.Errorf("未找到响度统计数据")
	}
	
	var stats LoudnessStats
	if err := json.Unmarshal([]byte(string(output)[jsonStart:]), &stats); err != nil {
		return nil, fmt.Errorf("解析响度数据失败: %w", err)
	}
	
	return &stats, nil
}

// NormalizeWithStats 第二遍精确归一化
func (s *LoudnormService) NormalizeWithStats(ctx context.Context, inputPath, outputPath string, stats *LoudnessStats) error {
	filterArgs := fmt.Sprintf("loudnorm=I=%.1f:TP=%.1f:LRA=%.1f:measured_I=%.2f:measured_LRA=%.2f:measured_TP=%.2f:measured_thresh=%.2f:offset=%.2f",
		s.targetLUFS, s.targetTP, s.targetLRA,
		stats.InputI, stats.InputLRA, stats.InputTP, stats.InputThresh, stats.TargetOffset,
	)
	
	cmd := exec.CommandContext(ctx, "ffmpeg",
		"-i", inputPath,
		"-af", filterArgs,
		"-c:a", "libmp3lame", "-q:a", "2",
		outputPath,
	)
	
	return cmd.Run()
}
```

### 11.2 音频分析服务

```go
// AudioStats 音频统计信息
type AudioStats struct {
	MeanVolume   float64 `json:"mean_volume"`   // 平均音量（dB）
	MaxVolume    float64 `json:"max_volume"`    // 最大峰值（dB）
	RMSLevel     float64 `json:"rms_level"`     // RMS 电平
	DynamicRange float64 `json:"dynamic_range"` // 动态范围
	HasClipping  bool    `json:"has_clipping"`  // 是否削波
}

// SilenceSegment 静音段
type SilenceSegment struct {
	Start    float64 `json:"start"`
	End      float64 `json:"end"`
	Duration float64 `json:"duration"`
}

// AudioAnalyzer 音频分析器
type AudioAnalyzer struct{}

// DetectVolume 检测音量统计
func (a *AudioAnalyzer) DetectVolume(ctx context.Context, inputPath string) (*AudioStats, error) {
	cmd := exec.CommandContext(ctx, "ffmpeg",
		"-i", inputPath,
		"-af", "volumedetect",
		"-f", "null", "-",
	)
	
	output, err := cmd.CombinedOutput()
	if err != nil {
		return nil, err
	}
	
	stats := &AudioStats{}
	lines := strings.Split(string(output), "\n")
	
	for _, line := range lines {
		if strings.Contains(line, "mean_volume:") {
			fmt.Sscanf(line, "[Parsed_volumedetect_0] mean_volume: %f dB", &stats.MeanVolume)
		} else if strings.Contains(line, "max_volume:") {
			fmt.Sscanf(line, "[Parsed_volumedetect_0] max_volume: %f dB", &stats.MaxVolume)
		}
	}
	
	stats.HasClipping = stats.MaxVolume > -0.1
	stats.DynamicRange = stats.MaxVolume - stats.MeanVolume
	
	return stats, nil
}

// DetectSilence 检测静音段
func (a *AudioAnalyzer) DetectSilence(ctx context.Context, inputPath string, threshold float64, minDuration float64) ([]SilenceSegment, error) {
	filterArgs := fmt.Sprintf("silencedetect=noise=%.1fdB:d=%.1f", threshold, minDuration)
	
	cmd := exec.CommandContext(ctx, "ffmpeg",
		"-i", inputPath,
		"-af", filterArgs,
		"-f", "null", "-",
	)
	
	output, err := cmd.CombinedOutput()
	if err != nil {
		return nil, err
	}
	
	var segments []SilenceSegment
	var currentSegment SilenceSegment
	
	lines := strings.Split(string(output), "\n")
	for _, line := range lines {
		if strings.Contains(line, "silence_start:") {
			fmt.Sscanf(line, "[silencedetect] silence_start: %f", &currentSegment.Start)
		} else if strings.Contains(line, "silence_end:") {
			fmt.Sscanf(line, "[silencedetect] silence_end: %f | silence_duration: %f",
				&currentSegment.End, &currentSegment.Duration)
			segments = append(segments, currentSegment)
		}
	}
	
	return segments, nil
}
```

### 11.3 批量响度归一化管道

```go
// BatchNormalizeResult 批量归一化结果
type BatchNormalizeResult struct {
	FilePath     string        `json:"file_path"`
	OriginalLUFS float64       `json:"original_lufs"`
	Success      bool          `json:"success"`
	Error        string        `json:"error,omitempty"`
}

// BatchNormalize 批量归一化（两遍，精确）
func (s *LoudnormService) BatchNormalize(ctx context.Context, inputFiles []string, outputDir string) []BatchNormalizeResult {
	results := make([]BatchNormalizeResult, len(inputFiles))
	
	for i, inputPath := range inputFiles {
		result := BatchNormalizeResult{FilePath: inputPath}
		
		// 第一遍：分析
		stats, err := s.AnalyzeLoudness(ctx, inputPath)
		if err != nil {
			result.Error = err.Error()
			results[i] = result
			continue
		}
		result.OriginalLUFS = stats.InputI
		
		// 构建输出路径
		base := filepath.Base(inputPath)
		outputPath := filepath.Join(outputDir, "normalized_"+base)
		
		// 第二遍：归一化
		if err := s.NormalizeWithStats(ctx, inputPath, outputPath, stats); err != nil {
			result.Error = err.Error()
			results[i] = result
			continue
		}
		
		result.Success = true
		results[i] = result
	}
	
	return results
}

// NewLoudnormService 创建响度归一化服务
// targetPreset: "streaming" (-16 LUFS) / "broadcast" (-23 LUFS) / "youtube" (-14 LUFS)
func NewLoudnormService(workDir, targetPreset string) *LoudnormService {
	targets := map[string][3]float64{
		"streaming": {-16, -1.5, 11},
		"broadcast": {-23, -1.0, 7},
		"youtube":   {-14, -1.5, 11},
	}
	t, ok := targets[targetPreset]
	if !ok {
		t = targets["streaming"]
	}
	return &LoudnormService{workDir: workDir, targetLUFS: t[0], targetTP: t[1], targetLRA: t[2]}
}
```

## 12. 动手实践

### 实验一：播客音频优化流水线

**目标**：对一段播客录音进行完整的音质优化处理。

```bash
# 完整播客优化命令
ffmpeg -i raw_podcast.mp3 \
  -af "highpass=f=100,\
       lowpass=f=10000,\
       equalizer=f=200:width_type=o:width=2:g=-3,\
       equalizer=f=3000:width_type=o:width=1.5:g=2,\
       compand=attacks=0.3:decays=0.8:points=-80/-80|-45/-20|-27/-12|0/-7:soft-knee=6,\
       loudnorm=I=-16:TP=-1.5:LRA=11" \
  -c:a libmp3lame -q:a 2 \
  podcast_final.mp3
```

**处理流程**：
1. `highpass=f=100`：去除 100Hz 以下的机械噪声、空调低频噪声
2. `lowpass=f=10000`：去除 10kHz 以上的麦克风高频噪声
3. `equalizer=f=200:g=-3`：削减 200Hz 浑浊感
4. `equalizer=f=3000:g=2`：提升 3kHz 语音清晰度
5. `compand`：压缩动态范围，让低音量说话变清晰
6. `loudnorm`：EBU R128 响度归一化到 -16 LUFS

**验证**：
```bash
# 处理前
ffmpeg -i raw_podcast.mp3 -af "volumedetect" -f null -

# 处理后
ffmpeg -i podcast_final.mp3 -af "volumedetect" -f null -
ffmpeg -i podcast_final.mp3 -af "loudnorm=I=-16:TP=-1.5:LRA=11:print_format=json" -f null -
```

### 实验二：视频背景音乐混音

**目标**：为视频添加背景音乐，音乐音量为人声的 20%，且在开头渐入、结尾渐出。

```bash
# 步骤1：提取原视频音频
ffmpeg -i video.mp4 -vn -c:a copy original_audio.aac

# 步骤2：背景音乐处理（降低音量、裁剪到视频长度、首尾淡入淡出）
ffmpeg -i bgm.mp3 -t 120 \
  -af "volume=0.2,afade=t=in:st=0:d=3,afade=t=out:st=117:d=3" \
  bgm_processed.mp3

# 步骤3：混音并合并到视频
ffmpeg -i video.mp4 -i bgm_processed.mp3 \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=first:dropout_transition=3[aout]" \
  -map 0:v -map "[aout]" \
  -c:v copy -c:a aac -b:a 192k \
  video_with_bgm.mp4
```

**进阶版**：自动闪避（背景音乐在人声出现时自动降低）

```bash
# 使用 sidechaincompress（人声为侧链输入）
ffmpeg -i video.mp4 -i bgm.mp3 \
  -filter_complex "\
    [1:a]volume=0.3[bgm];\
    [bgm][0:a]sidechaincompress=threshold=0.01:ratio=4:attack=200:release=1000[sc];\
    [0:a][sc]amix=inputs=2:duration=first[aout]" \
  -map 0:v -map "[aout]" -c:v copy -c:a aac video_ducking.mp4
```

### 实验三：批量响度归一化（Go 实现）

**目标**：批量处理一批音频文件，归一化到流媒体标准 -16 LUFS。

```go
package main

import (
	"context"
	"fmt"
	"log"
	"path/filepath"

func main() {

	service := NewLoudnormService("/tmp/audio", "streaming")
	
	// 输入文件列表
	inputFiles := []string{
		"episode_01.mp3",
		"episode_02.mp3",

		}
	}

}
```

## 13. 本章总结

本章系统梳理了 FFmpeg 音频滤镜的核心应用场景：

| 场景 | 滤镜 | 关键参数 |
|------|------|----------|
| 音量调整 | `volume` | 线性倍数 / dB 值 |
| 响度归一化 | `loudnorm` | `I`（LUFS）、`TP`（dBTP）、两遍法 |
| 动态压缩 | `compand` | `attacks`、`decays`、传递函数 `points` |
| 变速不变调 | `atempo` | 范围 0.5-2.0，链式突破 |
| 声道控制 | `pan` / `channelmap` | 声道混合公式 |
| 多路混音 | `amix` / `amerge` | `inputs`、`duration`、`dropout_transition` |
| 均衡器 | `equalizer` / `bass` / `treble` | `f`（频率）、`g`（增益dB）、`Q` |
| 音频分析 | `volumedetect` / `astats` | 无参数（提取统计数据） |
| 静音检测 | `silencedetect` | `noise`（阈值dB）、`d`（最小时长秒） |
| 降噪 | `afftdn` | `nr`（强度）、`nf`（噪声本底） |

**关键原则**：
1. **两遍响度归一化**优于单遍，精度更高
2. **atempo 链式调用**可突破 0.5-2.0 的单次限制
3. **先滤波再压缩再归一化**是标准音频处理顺序
4. **amix 用于叠加**，amerge 用于声道合并，目的不同
5. Go 集成时注意 stderr 解析（ffmpeg 统计输出到 stderr）

## 14. 术语表

| 术语 | 英文全称 | 说明 |
|------|----------|------|
| LUFS | Loudness Units Full Scale | 响度单位，感知音量测量标准 |
| LU | Loudness Unit | 响度单位差值（1 LU = 1 dB 差异） |
| LRA | Loudness Range | 响度范围，衡量动态变化程度（LU） |
| TP | True Peak | 真峰值，考虑插值后的实际峰值（dBTP）|
| EBU R128 | EBU Recommendation R128 | 欧洲广播联盟响度标准，-23 LUFS |
| RMS | Root Mean Square | 均方根，衡量平均功率/音量 |
| dBFS | dB Full Scale | 以数字满幅为基准的分贝值（0 dBFS = 最大值）|
| 动态范围 | Dynamic Range | 最大值与最小值的差（dB）|
| 削波 | Clipping | 信号超过最大值被截断，产生失真 |
| 侧链 | Sidechain | 用一路信号控制另一路信号的处理（如音量闪避）|
| 闪避 | Ducking | 背景音乐在人声出现时自动降低音量 |
| 高通滤波 | High-pass Filter | 允许高频通过，衰减低频噪声 |
| 低通滤波 | Low-pass Filter | 允许低频通过，衰减高频噪声 |
| 参数均衡 | Parametric EQ | 可调中心频率、增益、Q 值的均衡器 |
| Q 值 | Quality Factor | 均衡器频率选择性，Q 越大带宽越窄 |
| 噪声门 | Noise Gate | 低于阈值时静音，高于阈值时开放信号 |
